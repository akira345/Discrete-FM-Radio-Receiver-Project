## 9. 組み立て順序と確認ポイント

1. 3本のバスと c0 の連結線を張る
2. バイアス分圧（RVBU/RVBL/C0）を付けて **VBU = 2.34V、VBL = 1.57V** を確認
3. ギルバートセル本体 → 無信号で **OA ≒ OB ≒ 3.4V、ET ≒ 0.8V** を確認
4. 上段・下段ドライブ、裏ジャンパ
5. 位相シフト部（IFT はコアを回せる向きに）
6. 出力段 → **Q16 エミッタ 2.8V** を確認
7. S4A / S4B を IF 基板から接続。**Cc は必ずこちらの基板側**に実装すること
   （配線のストレー容量がタンク側に乗るのは同調で吸収できるが、Cc を向こう側に置くと 1pF が配線容量に埋もれる）

### 基板間の接続は4本だけ
S4A ／ S4B ／ +5V ／ GND。S4A・S4B は 330Ω の低インピーダンスなので、
撚り線でも同軸でも構いません。GND は太めに。
