## det_board.md / det_board.png（検波部 万能基板 配線図）

### 誤り1：SOT-23 が鏡像配置になっている

QU1/QU2、QU3/QU4、QL1/QL2 の3組すべてで、ペアの一方が鏡像に描かれています。

**SOT-23 は裏返して配置できません。** ピン1 = B、ピン2 = E が同じ側、ピン3 = C が反対側に単独。
鏡像に置くと B と C が入れ替わります。差動対は必ず**点対称（180° 回転）**で配置してください。

**検算方法**：すべてのトランジスタについて `sign((B→E) × (B→C))` を計算し、
全個体で符号が一致することを確認する。

### 誤り2：コレクタの 1000p が VCC に落ちている

`CLA` / `CLB`（QU の負荷 1.5kΩ と並列の 1000p）が **+5V バス**に接続されています。
交流的には等価ですが、**GND バス①（RTG と同じバス）に戻してください。**
リターン電流の経路が変わるうえ、ネットリスト（`CLA OA 0 1000p`）とも食い違います。

### 誤り3：ネットリストとの不一致（不具合ではない）

配線図は裏面ジャンパで **OB** を出力段に繋いでいますが、
試作時のネットリストは `RF1 OA LP 1k`（OA から取り出し）でした。

**実機は OB 側で正しく動作しています。** ただし S カーブの極性が反転し、
**周波数上昇で出力電圧が上昇**します。`netlist/ifsys_final.net` は OB に修正済みです。

### 注記

このレイアウト自体は採用されていません（実装配置は製作者が決定）。
**配線の接続関係（ネットリスト）の参考としてのみ**使ってください。

## check.md（リミッタ配線チェックリスト）

本文は訂正済みですが、以下の点に注意してください。

### 判定基準 |OUT A − OUT B| ≤ 50 mV は厳しすぎる

検波部の OA/OB について、実測で 146 mV の差が出ました。
これは **ΔVbe わずか 2.3 mV** に相当し、ディスクリートの Vbe ばらつき ±5 mV を考えれば正常範囲です。

**判定基準は ±300 mV としてください。**（リミッタ段の OUT A/OUT B も同様）

なお、**DC バランスでは上段クアッドの交差配線ミスは検出できません。**
それを検査できるのは S カーブのスイープだけです（`docs/HANDBOOK.md` STEP 3）。

### E（共通エミッタ）についての訂正は本文に反映済み

「E が 0.6〜0.9 V なら片側だけ導通」という記述は誤りで、本文 83 行目以降で訂正されています。
**E は何石導通しているかの判定には使えません。** Vbe は電流が2倍になっても 18 mV しか動きません。
判定にはコレクタ電圧か総電源電流を使ってください。

### 最重要の指標は E ではなく BA

発振の有無は **BA / BB の8点測定**で判定します。

```
BA = VB − Ib × RGA
  正常   : 1.98〜2.00 V （Ib = 13.5 µA）
  発振中 : 1.5〜1.6 V   （Ib = 57 µA）← ベース整流 ＝ Class-C 動作
```

`figures/chk_stage.png` は修正版で、BA を最重要として強調してあります。
