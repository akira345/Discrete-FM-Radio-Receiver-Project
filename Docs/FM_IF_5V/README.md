# 5V FM チューナ ── フルディスクリート版

**フロントエンド**（ゲート接地RF ＋ コルピッツ局発 ＋ LOバッファ ＋ ソース注入ミキサ ＋ 整合IFT）
＋ **IF ストリップ**（4段差動リミッタ ＋ ギルバート型クワドラチャ検波）
**5 V 単一電源 / IF 10.7 MHz / 日本ワイドFM 76–95 MHz / TA7358P 代替**

80〜90年代の FM ラジオ IC の中身を、ディスクリート部品で組み直す試み。

> ## ✅ 実放送の受信に成功しました（2026-09-23）
>
> フロントエンド ＋ リミッタアンプ ＋ 検波段を接続し、**約 1 m のビニール線**で実際の FM 放送を受信。
> **ワイドFM の上限からローカル FM 局の下限まで**、設計帯域の全域をカバーすることを確認しました。
> 万能基板・シールドケース無しでの達成です。

## 図版の整合性について

このプロジェクトでは試行錯誤の過程で **25 枚の図版**が生成されましたが、
そのうち最終設計と整合するのは **11 枚**だけです。
本パッケージには整合するものだけを収録しています。

**除外したもの（設計が変わったため）**

| 除外した図 | 理由 |
|---|---|
| 旧・全体回路図 | 移相回路がセラミックディスクリミネータ（J10.7C）版。**IFT タンクに変更済み** |
| AFC 関連図 | AFC はプロジェクト途中で不採用 |
| ディスクリミネータの特性フィット図 | 上記の変更により無効 |
| 初期の基板フロアプラン・部品配置案 | 万能基板の試作用。専用基板では使わない |
| 4段目の発振対策図 | 局所対策として描いたが、**真因はグラウンドの伝導結合**だった。誤誘導になるため除外 |
| ギルバートセル動作説明図 | 旧版の定数を含む |

**主な設計変更の履歴**

- 移相回路：セラミックディスクリミネータ J10.7C → **自作 IFT タンク**（2.21 µH / 100p / 4.7k）
- それに伴い Cc 2.2p → **1p**、Ct → **CP 100p**、Rp 2.7k → **4.7k**
- 4段目出力に**終端 CR（1000p + 1kΩ）を追加**
- ピーキングコイル：全段 6.8 µH → **1・2段目のみ**（3・4段目は 0Ω）
- AFC：**不採用**
- 出力の取り出し：OA → **OB**（S カーブの極性が反転）

専用基板（両面ベタGND）の設計。`HANDBOOK.md` 第8章に申し送り事項をまとめてあります。
要点は3つ：

1. **CLA / CLB は GND バスへ**（万能基板版では VCC に落ちている）
2. **SOT-23 の鏡面配置禁止**。`sign((B→E)×(B→C))` を全個体で検算する
3. **ベタGND ＋ 縫いビア**。ガードリング＋一点接地は RF では逆効果
