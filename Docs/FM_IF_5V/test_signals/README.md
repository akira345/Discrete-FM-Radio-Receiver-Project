# AD3 用 FMステレオ コンポジット（MPX）試験信号

NJM2035 の代わりに、Analog Discovery 3 の WaveGen で**規格どおりのコンポジット信号**を出すためのデータです。
使い方の背景は `docs/MPX_DECODER.md` 第2章。

## 規格式

```
m(t) = 0.45(L+R) + 0.45(L−R)·sin(2ωp t) + 0.10·sin(ωp t)      ωp = 2π×19000
```

1周期のバッファに **音声1サイクル / パイロット19サイクル / 副搬送波38サイクル**を収めてあるので、
WaveGen の **Frequency を 1 kHz** にすると 19 kHz と 38 kHz が誤差ゼロで出ます。

## ファイル

| ファイル | 内容 | 用途 |
|---|---|---|
| `mpx_L1k.csv` | L のみ 1 kHz | **L→R セパレーション** |
| `mpx_R1k.csv` | R のみ 1 kHz | **R→L セパレーション** |
| `mpx_mono1k.csv` | L = R 1 kHz | L−R = 0。L+R 経路の確認 |
| `mpx_diff1k.csv` | L = −R 1 kHz | L+R = 0。L−R 経路だけの確認 |
| `mpx_pilot.csv` | パイロットのみ | パイロット漏れ・パイロット経路の測定 |
| `mpx_L1k_p+37.csv` ほか | パイロットの位相だけ ±37° ずらした L / R | **パイロット経路の位相遅れの診断用** |
| `make_mpx.py` | 生成スクリプト | 周波数や変調度を変えたいとき |
| `preview_check.png` | WaveForms のプレビューの正しい形 | 読み込み後の照合用 |
| `mpx_L1k_check.png` | mpx_L1k の波形とスペクトル | |

各ファイル 4096 サンプル、1行1値。

## 検証済みスペクトル（mpx_L1k.csv）

| 成分 | 振幅 | 1 kHz 比 | 規格 |
|---|---|---|---|
| 1 kHz（L+R） | 0.4664 | 0 dB | 0 dB |
| 19 kHz（パイロット） | 0.1036 | **−13.07 dB** | −13.1 dB |
| 37 kHz（L−R 下側波） | 0.2332 | **−6.02 dB** | −6.02 dB |
| 39 kHz（L−R 上側波） | 0.2332 | **−6.02 dB** | −6.02 dB |
| 38 kHz（キャリア） | 0 | −∞ | 抑圧 |
| その他すべて | < 1e−16 | — | なし |

53 kHz より上に成分はありません。実放送と同じ条件です。

## WaveForms への読み込み

1. WaveGen の波形タイプ（`Simple` と書かれている所）で **`Custom`** を選ぶ
2. CSV をインポートする。**Import 画面の Frequency 等には触らず、そのまま OK**
3. 出力パネルで **Frequency = 1 kHz**、**Offset = 0 V**
4. プレビューの形を `preview_check.png` と照合する
5. **Amplitude = 200 mV**（mpx_L1k / R1k / 位相ずらし版）

> **不具合**：Import 画面で Frequency を入力すると Sample rate と入れ替わり、波形がクリップします。

### Amplitude について

- **100 mV ではステレオ判定されず VCO が止まります**（現行基板）。200 mV を使ってください
- WaveForms は**ファイルごとに自分のピークで正規化**します。
  `mpx_pilot.csv` を他と同じパイロット量で出すには **20.7 mV**（＝200 mV × 0.1036）にします。
  200 mV にすると 10 倍のパイロットになります
- `mpx_mono1k`（ピーク 1.024）と `mpx_diff1k`（1.006）も同様に、振幅がわずかにずれます

## スペクトラムの設定

| 設定 | 値 | 理由 |
|---|---|---|
| Stop | **200 kHz** | Stop 2 kHz だと 19 / 37 / 39 kHz が 1 kHz に折り返す |
| Window | Flat Top | 振幅が正確（ただし約 24 Hz 以内の2本は分離不可） |
| 読む値 | 1 kHz の**振幅と位相** | 位相で漏れが同相か逆相かを判別 |

## 手順

| 手順 | ファイル | 見るもの |
|---|---|---|
| 1 | `mpx_L1k` | Scope で波形を確認（発生器の出力が正しいか） |
| 2 | `mpx_L1k` | L 出力（主）と R 出力（漏れ）の 1 kHz → **L→R セパレーション** |
| 3 | `mpx_R1k` | 逆方向 |
| 4 | 漏れの位相 | 主信号と同相なら RV2 が小さい、逆相なら大きい |

**RV2 を触る前に、必ず現在位置に印を付けること。**

## 位相ずらし版の使い方（診断）

セパレーションが悪いとき、原因が**パイロット経路の位相**かどうかを回路を触らずに確かめられます。

| 結果 | 判定 |
|---|---|
| p+37 で大きく改善 | パイロットが約 37° 遅れている（本プロジェクトでは 31.5 dB に改善） |
| p−37 で L と R が入れ替わる | 遅れの向きも確定 |
| どちらでも変わらない | 原因はパイロット位相以外 |

## 注意

- **L と R が入れ替わって出る場合**、復調器の 38 kHz の位相が 180° ずれています。
  実放送で正しく聞こえているなら復調器は正しいので、この信号側は触らないでください
- NJM2035 は時分割変調器で出力フィルタが無く、L−R が実放送より 2.77 dB 大きく復調されます。
  RV2 の調整にはこちらの信号を使ってください
