# MPX ステレオデコーダ 設計・調整記録

**対象**：74HC4046 PLL ＋ TC4066 スイッチング復調 ＋ NJM2747 によるステレオデコーダ（基板 `MPXDecorder-V3_SMD`）
**電源**：5 V 単一 ／ **入力**：IF 基板の MPX OUT（rev.E 利得段の後）
**試験信号**：Analog Discovery 3 の WaveGen で生成した規格どおりのコンポジット（`test_signals/`）

2026-09 のデバッグ記録。セパレーションが 10 dB 前後しか出なかった原因を突き止め、**31〜37 dB** まで改善した経緯と、
専用基板・次期設計への申し送りをまとめます。

---

## 0. 結論（先に読む）

| 項目 | 内容 |
|---|---|
| 症状 | セパレーション不足、RV2 を回すと L/R 両方の出力が一緒に動く |
| 真因 | **パイロット BPF の位相遅れ**。NJM2747 の GB 積 10 MHz が MFB BPF（Q≈9）には不足し、ピークが 19.03 → 18.70 kHz にずれて 19 kHz で約 34° 遅れた |
| 38 kHz ゲートの誤差 | θ ≈ 74°（BPF 2段 ＋ LM393 の 0.49 µs）→ 復調効率 k ≈ 0.175 |
| 対策 | R21 / R27（47 Ω）に **1.5 kΩ を並列**（実測 45.5 Ω）、RV2 を **固定 2.2 kΩ** に |
| 結果 | **L→R 37.1 dB ／ R→L 31.4 dB**、主信号 −22.9 dBV（対策前より約 8 dB 大きい） |
| 次の一手 | RV2 を 2.2k ∥ 39k（2.08 kΩ）→ 両方向とも約 40 dB の見込み |
| IF 基板の検波後 LPF | 220 pF。RV2 補正後は 15 kHz でも約 58 dB で、**セパレーションのボトルネックではない**（当初 35.2 dB としたのは補正なしの最悪値。HANDBOOK 11.2 の訂正） |

> **構造的な教訓**：位相精度が要る経路に高 Q フィルタを直列に置いたことが根本原因です。
> 専用 IC（BA1332L、TA7343AP など）はコンポジットを VCO 由来の 19 kHz で**直接同期検波**して PLL を組むため、
> この故障モードを原理的に持ちません（第8章）。

## 1. 構成

```
J1 (MPX) ─┬─ U2C バッファ（2.5 V バイアス）─┬─ U1A（38KHz-PLL = H で ON）→ SIG-L → 4次 SK LPF ─┐
          │                                 └─ U1D（38KHz-PLL = L で ON）→ SIG-R → 4次 SK LPF ─┤
          │                                                                                    └→ U7 マトリクス → デエンファシス → OUT-L / OUT-R
          │
          └─ Q1（CE, 実効利得 約3）→ U2A MFB BPF → U2B MFB BPF → C16/R32 → U4A（LM393）→ 19KHzRect（TP2）
                                                                                              │
                              74HC4046 PC2 ← RefIn ← U5A（19 kHz）← U5B（38 kHz）← VCO 76 kHz
```

| ブロック | 部品 | 要点 |
|---|---|---|
| スイッチ | U1A / U1D（TC4066） | ゲートは Q3/Q4・Q5/Q6 の NAND 段、プルアップ 1 k。R33/R35（10 k）に **220 pF のスピードアップ C** |
| パイロット増幅 | Q1 | BPF の重い負荷で実効利得は約3倍 |
| BPF 1段目 | R20 2.4k / R21 47Ω / R25 15k / C11・C12 0.01µ（C0G） | Q ≈ 9 |
| BPF 2段目 | R26 7.5k / R27 47Ω / R29 15k / C14・C15 0.01µ（C0G） | Q ≈ 9 |
| 経路利得 | Q1 入力 → U2B 出力 | 9.15 倍 |
| コンパレータ | U4A（LM393）、R37 10 k プルアップ | 伝搬遅延 0.49 µs（38 kHz で 3.4°） |
| PLL | 74HC4046 PC2 ＋ 74HC74 | VCO 76 kHz → 38 kHz → 19 kHz。38 kHz の立ち上がりが TP2 の立ち上がりに揃う |
| ステレオ判定 | Q2 → D1 → PILOT-V と 2.5 V を U4B で比較 | **ヒステリシス無し**。R24 は実装 1 k（回路図表記ミス） |

### 1.1 マトリクス（U7）と RV2

ネットリストから導いた式（r = RV2 / 10 k、範囲 0〜0.5）：

```
U7A   = −r·(SIG_L + SIG_R)
OUT_L = −[(1−r)·SIG_L − r·SIG_R]
OUT_R = −[(1−r)·SIG_R − r·SIG_L]
デエンファシス：10 k × 4700 p = 47 µs（日本の規格 50 µs に近い値）
```

スイッチの復調効率を k（理想の矩形スイッチで k = (2/π)·cosθ、θ は 38 kHz ゲートの位相誤差）とすると、
反対チャンネルへの漏れ係数は

```
漏れ ∝ 1 − k − 2r       →   最適値  r = (1 − k) / 2
```

- **同相の漏れ**（FFT の位相が主信号とほぼ同じ）＝ RV2 が小さすぎ
- **逆相の漏れ**（位相が約 180° 違う）＝ RV2 が大きすぎ
- **RV2 を回すと L/R 両方の出力が一緒に動くのは設計どおり**（どちらのチャンネルにも r が入る）

θ が大きいと k が小さくなり、最適 r が 0.5 に張り付いて**補正しきれなくなります。** これが当初の症状でした。

## 2. 測定方法（AD3）

### 2.1 試験信号

`test_signals/` の CSV を WaveGen の Custom で出します（詳細は同フォルダの README）。

```
m(t) = 0.45(L+R) + 0.45(L−R)·sin(2ωp t) + 0.10·sin(ωp t)
```

| 設定 | 値 | 理由 |
|---|---|---|
| Frequency | **1 kHz** | バッファに 1 kHz × 1 周期、19 kHz × 19、38 kHz × 38 が入っている |
| Amplitude | **200 mV**（mpx_L1k / R1k） | 100 mV ではステレオ判定されず VCO が止まる |
| mpx_pilot 単体 | **20.7 mV** | WaveForms はファイルごとにピークで正規化するので、同じ 200 mV だと10倍のパイロットになる |

> **WaveForms の不具合**：Import 画面で Frequency を入力すると Sample rate と入れ替わり、波形がクリップします。
> **Import 画面は触らずに OK** → 出力パネルで Frequency = 1 kHz → プレビューの形を `preview_check.png` と照合。

### 2.2 NJM2035 を使わない理由

NJM2035 は時分割変調器で出力フィルタが無く、**パイロットは矩形波（デューティ 54.2 %）**、
L−R が 38 kHz だけでなく 114 kHz（1/3）と 190 kHz にも乗っています。
スイッチング復調すると L−R が**実放送より 2.77 dB 大きく**復調されるため、RV2 の最適点がずれます。

### 2.3 スペクトラム

| 設定 | 値 | 注意 |
|---|---|---|
| Stop | **200 kHz**（サンプリング 400 kHz） | Stop 2 kHz にすると 19/37/39 kHz が 1 kHz に折り返す（エイリアス） |
| Window | Flat Top | 振幅が正確。ただし約 24 Hz 以内の2本は分離できない |
| 読む値 | 1 kHz の振幅と**位相** | 位相で同相／逆相の漏れを判別できる（1.1 節） |
| プローブ | 両 ch とも AC 結合 ×1 | デエンファシス後の音声出力を測る |

**RV2 などを調整する前に、必ず現在位置に印を付けること。**（一度これを怠って最初からやり直しになった）

## 3. 原因の特定

### 3.1 パイロット経路の位相（ngspice、`netlist/pilot_ac.cir`）

| 条件 | 19 kHz 利得 | 19 kHz 位相 | ピーク周波数 |
|---|---|---|---|
| 理想オペアンプ | 9.18 倍 | −177.6° | 19.03 kHz |
| **GB 積 10 MHz（NJM2747）** | **8.44 倍** | **−211.8°** | **18.70 kHz** |
| **実測（Pilot_test）** | **8.85 倍** | **−213.7°** | — |
| 10 MHz ＋ R21/R27 = 45.5 Ω | 9.14 倍 | −180.2° | 19.03 kHz |
| 50 MHz ＋ 45.5 Ω（並列を外し忘れた場合） | 8.63 倍 | −151.8° | 19.25 kHz |

MFB BPF はオペアンプの有限 GB 積で中心周波数が下がります。Q ≈ 9 だと中心の 1 % のずれで 1 段あたり約 10° 動くので、
**2段で 34° の遅れ**。38 kHz ではこれが2倍になり、LM393 の遅延 3.4° を足して **θ ≈ 74°** になりました。

### 3.2 GB 積と θ の関係（R21/R27 = 47 Ω、補正なし）

```
θ ≈ −680 / GBW[MHz] − 2°      （38 kHz ゲートの位相誤差）
```

| GB 積 | θ |
|---|---|
| 10 MHz | 約 −70〜−74° |
| 20 MHz | −37° |
| 30 MHz | −25° |
| 40 MHz | −19° |
| **50 MHz** | **−16°** |
| 100 MHz | −9° |

### 3.3 仮説の検証：パイロット位相をずらした試験信号

「パイロットが遅れている」ことを実機で確かめるため、**パイロットだけ位相を ±37° ずらした**コンポジット
（`mpx_L1k_p+37.csv` など）を作って入力しました。

| 試験信号 | 結果 | 意味 |
|---|---|---|
| p+37（パイロットを先に進めておく） | **セパレーション 31.5 dB** | 遅れを打ち消すと直る＝原因はパイロット位相 |
| p−37（さらに遅らせる） | **L と R が入れ替わる** | 向き（遅れ）も確定 |

**回路を触らずに、試験信号側で仮説を検証できた**のが決め手でした。

### 3.4 否定された仮説（再発防止）

| 仮説 | 否定した根拠 |
|---|---|
| NJM2035 の異常発振 | AD3 生成の規格信号でも同じ症状 |
| Q3〜Q6（SOT-23）の逆実装 | ゲート駆動波形を実測して正常 |
| R37 を 2.2 k にして LM393 の立ち上がりを速くする | 遅く見えたのは ×1 プローブの容量負荷。不要 |
| BPF コンデンサ（X7R）の温度ドリフト | 実装は C0G |
| ステレオ判定の SPICE（パイロット無しでもステレオ判定される） | 実機と矛盾。モデルの誤り |

## 4. 対策と結果

### 4.1 BPF の補正（NJM2747 のまま）

R21 / R27（47 Ω）に **1.5 kΩ を並列**。周辺回路込みの実測で 45.5 Ω。
BPF の中心を約 1.7 % 上げ、GB 積不足によるずれを打ち消します（3.1 節の4行目）。

### 4.2 RV2

調整中に RV2（5 k 単回転）が破損。破損前の3点から k を逆算しました。

| RV2 位置 | Ch1 | Ch2 |
|---|---|---|
| 右端 | −19.969 dBV | −31.530 dBV |
| 左端 | −28.460 dBV | −29.238 dBV |
| 中間 | −24.75 dBV | −45.63 dBV |

```
フィット結果：k = 0.564  →  最適 RV2 = 2.18 kΩ
35 dB を得る許容幅：±100 Ω（5 k 単回転の ±2 % の回転角）
```

**5 k 単回転では細かすぎて合わせられません。** 固定抵抗 2.2 kΩ で代用しました。

### 4.3 結果（RV2 = 2.2 kΩ 固定）

| 項目 | 値 |
|---|---|
| L→R | **37.1 dB** |
| R→L | **31.4 dB** |
| 漏れの位相 | 主信号に対して 163〜165°（**逆相 ＝ RV2 がわずかに大きい**） |
| 主信号 | −22.93 / −22.81 dBV（対策前 −30.6 dBV から約 8 dB 増） |

主信号が 8 dB 増えたのは、θ が小さくなって復調効率 k が上がったためです。

### 4.4 さらに詰めるなら

| 案 | 見込み |
|---|---|
| 2.2k ∥ 39k（2.08 kΩ） | L→R 約 42 dB ／ R→L 約 40 dB |
| 1.8k 固定 ＋ 500 Ω 半固定（手持ちで可） | 同上。調整可能 |
| それ以上 | 直交成分の漏れ（約 −43〜−48 dB）で頭打ち |

## 6. 既知の注意点

| 項目 | 内容 |
|---|---|
| 入力レベルの窓が狭い | ステレオ判定には コンポジット約 0.4 Vpp（パイロット約 41 mVpp）以上が必要。一方 Q1 は約 0.3 Vpp まで線形で、**0.5 Vpp を超えると L/R の内容に応じてパイロット位相が動く**（0.7 Vpp で 38 kHz 換算 14.5°、1 Vpp で 26°） |
| ステレオ判定 | U4B にヒステリシスが無く、境界レベルでばたつく可能性 |
| オペアンプ交換時 | GB 積 50 MHz 品に替えるなら **1.5 k の並列を外す**。付けたままだと θ ≈ +47°（進みすぎ） |
| 検波後の「ガビガビ」波形 | ポケットオシロと AD3 の比較が未了（測定系の問題の可能性） |

## 7. 専用基板への申し送り

1. **U2 を高速品に**、または R21 / R27 に**並列抵抗用のパッド**を用意する
2. BPF のコンデンサは **C0G ±2 %**
3. **RV2 は固定抵抗＋小さい半固定**（例：1.8 k ＋ 500 Ω）。5 k 単回転は不可
4. **ステレオ判定と Q1 過入力の窓を広げる**（判定にヒステリシス、Q1 の利得配分の見直し）
5. 可能なら**パイロット検出を同期検波方式に変更**（第8章、シミュレーションで 38 kHz 誤差 0.4°）

## 8. 次期設計案：コンポジットの同期検波で PLL を組む（ngspice で動作確認済み）

> 回路図：`figures/mpx_sync_block.png`（全体）、`figures/mpx_sync_detail.png`（新規部分）
> シミュレーション：`netlist/sync_pll.tmpl` ＋ `scripts/sync_run.py`（理想スイッチ・単極オペアンプ・VCO/分周器は動作モデル）
> **実機未検証。** VCO 利得は仮定値です（8.6 節）。

### 8.1 考え方

現行は「パイロットを BPF で取り出す → コンパレータで矩形にする → PC2 で位相比較」の3段で、
**PC2 が綺麗な矩形を要求するために BPF が必要になり、その BPF の位相感度がセパレーションを決めていました。**
しかし PLL 自体がすでに狭帯域フィルタなので、BPF は本来いりません。

専用 IC と同じく、**VCO から作った 19 kHz でコンポジットを直接掛け算**すれば、

- 音声（〜15 kHz）と L−R（23〜53 kHz）は平均するとゼロになり、パイロットの成分だけが残る
- ロックしたときの位相は分周器の論理で決まり、**部品定数やオペアンプの GB 積に左右されない**

### 8.2 変わるところ・変わらないところ

| ブロック | 扱い |
|---|---|
| J1 → U2C バッファ → U1A / U1D → SK-LPF（U6）→ マトリクス（U7）→ デエンファシス | **現行のまま** |
| ゲート駆動 Q3〜Q6、STEREO LED（U1B / D2）、VREF（U2D） | **現行のまま** |
| U5A / U5B の分周（76k → 38k → 19k） | **現行のまま** |
| 74HC4046 | **VCO としてだけ使う**（PC2 とそのループフィルタは撤去） |
| 位相比較・ループフィルタ・90° FF・ステレオ検出 | **新規** |
| パイロット BPF 経路・旧ステレオ判定・VCO 停止 | **撤去** |

### 8.3 逓倍の仕組みは現行と同じ

現行も新案も、**VCO 76 kHz を ÷4 した 19 kHz をパイロットと比較して**ロックさせています。これが 19 kHz → 76 kHz の「逓倍」の正体で、分周器（U5）はそのまま使います。変わるのは**位相比較器に何を入れるか**だけです。

| | 位相比較器 | 入力 A | 入力 B（VCO 側） | ロック点 |
|---|---|---|---|---|
| 現行 | 4046 PC2（デジタル） | 19KHzRect（BPF → LM393） | I（U5A の Q） | エッジ一致（0°） |
| 新案 | U8A ＋ U2A（±1 乗算） | **コンポジットそのもの** | **Q（I を 90° 遅らせたもの）** | **直交（90°）** |

**なぜ I ではなく Q を使うか**：掛け算型の位相比較器は、2 つの信号が **90° ずれたところで出力がゼロ**になりロックします。
I をそのまま入れると I がパイロットと 90° ずれてロックしてしまうので、あらかじめ 90° 遅らせた Q を入れます。
すると **I がパイロットと揃い（シミュレーションでは逆相、現行 PC2 と同じ関係）**、38 kHz の立ち上がりがパイロットのゼロクロスに一致します。

**Q の作り方**：新規の 74HC74（U9A）の D に I、CK に /38k（U5B の /Q）を入れます。
I は 38k の立ち上がりで変化するので、半周期後の立ち下がりで取り込むと **19 kHz の 1/4 周期＝ちょうど 90° 遅れ**ます。
論理だけで決まる 90° なので、部品のばらつきはありません。

**PLL は 1 つだけ**：ステレオ検出（U8B / U8C）も同じ I・/I を使う同期検波ですが、VCO を制御しないので PLL ではありません。

### 8.4 回路（`figures/mpx_sync_detail.png`）

| ブロック | 構成 | 定数 |
|---|---|---|
| ① 位相比較 | U2A の反転アンプ（R61 / R62）＋非反転入力を U8A で VREF に落とす → Q=H で −1 倍、Q=L で +1 倍 | R60〜R62 10k |
| ② ループフィルタ | U2B の PI 積分。R63 入力、R64 ＋ C40 で零点、C41 で 19 kHz 以上のリップル除去 | R63 47k、R64 7.5k、C40 1µ、C41 10n |
| ③ VCO | 4046 の VCOin（9）に VCTL。INH（5）は GND で常時動作。3・14 は GND、PC2（13）はオープン | 現行の R1 / R2 / C4 / RV1 |
| ③ 90° FF | U9A：D=I、CK=/38k、/S・/R は +5V | — |
| ④ ステレオ検出 | U8B（I）と U8C（/I）で composite を別々の RC に振り分け、SA・SB の差を U4B で比較 | R66 / R67 10k、C42 / C43 1µ |
| ④ しきい値 | R68 10k、R69 2.2M（GND）、R70 4.7M（出力へ・ヒステリシス） | 計算値。**要調整** |

**ステレオ検出の原理**：I=H の間の composite の平均（SA）と I=L の間の平均（SB）は、パイロットがあると
±(2/π)×パイロット振幅だけ離れます。音声と L−R はどちらにも等しく入るので差には出ません。
**両方に同じバイアスが乗るので、U2C のバイアス誤差の影響を受けません。**

**VCO は常時動作させる**：新方式は VCO の I でパイロットを検出するので、パイロットが無いときに VCO を止めると
二度とステレオになりません。現行の VCO 停止（U1C・R8）は撤去します。

### 8.5 シミュレーション結果

条件：L のみ 1 kHz 100 %、パイロット 10 %、J1 入力 1 Vpp、オペアンプ GB 積 10 MHz・SR 3 V/µs。

| ケース | 38 kHz 位相誤差 | 備考 |
|---|---|---|
| 基準 | **0.4°** | 現行 NJM2747 構成は約 74°。ジッタ 0.6° pp |
| 任意の初期位相から | 0.4° | ロックまで約 80 ms |
| VCO 自走 ±1 % ずれ | 0.4° | ロックまで約 220 ms |
| VCO 自走 ±3 % ずれ（2 Vpp） | 1.0° | ロックする（1 秒間の解析内） |
| 入力 0.5 Vpp / 2 Vpp | 0.3° / 1.0° | |
| U2C のバイアス誤差 20 mV | 0.7° | 全波の掛け算なので DC 誤差が消える |
| オペアンプ Vos 3 mV（同符号・1 Vpp） | 11° | **固定の誤差なので RV2 で吸収できる** |
| Vos +3 / −3 mV・自走 ±3 %（2 Vpp） | 6.4° | ロックする |
| パイロット無し | — | SB−SA ≈ 0.3 mV（モノラル判定） |
| ステレオ検出 SB−SA | — | 1 Vpp で 65 mV、2 Vpp で 131 mV |

38 kHz の位相誤差 θ は、DSB である L−R を cosθ 倍するだけです。固定値なら RV2 で補正でき、11° でも cos = 0.98 です。
**問題になるのは入力レベルや温度で θ が動くことですが、FM はリミッタの後なのでパイロットのレベルはほぼ一定です。**
