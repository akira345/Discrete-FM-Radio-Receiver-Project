# 5V FM IF ストリップ 設計・調整ハンドブック

**対象**：4段差動リミッタアンプ ＋ ギルバート型クワドラチャ検波器（フルディスクリート）
**電源**：5 V 単一 ／ **IF**：10.7 MHz ／ **用途**：日本ワイドFM 76–95 MHz、TA7358P 代替
**出力先**：74HC4046 PLL ステレオデコーダ（MPX）

万能基板による基礎実験が完了した時点の記録。専用基板設計フェーズへの申し送りを含む。

> **2026-09-23：フロントエンドと接続し、約 1 m のビニール線で実放送の受信に成功。**
> ワイドFM の上限からローカル FM 局の下限まで、設計帯域の全域をカバー。
> 万能基板・シールド無し。IF 部単体の実測性能（本文）が実受信でも成立することが確認されました。

## 1. 全体構成

```
フロントエンド(2SK3557)
   ↓ 10.7 MHz
セラミックフィルタ SFELF10M7GA00   ← 330Ω 直列で駆動、330Ω で終端
   ↓
[ リミッタ 1段目 ] → [ 2段目 ] → [ 3段目 ] → [ 4段目 ]     合計 70.4 dB
   ↓ S4A / S4B （差動 3.0 Vpp）
[ 検波基板 ]
   ├─ Cc 1p → IFTタンク(2.21µH // 100p // 4.7k) → 2SK3557 ソースフォロア → 下段差動対
   └─ 1000p → 分圧(5.6k+1k) → 上段クアッド
   ↓ ギルバートセル → OB
[ CR LPF 1k+1000p ] → [ エミッタフォロア Q16 ] → 10µF → MPX OUT
```

**設計の背骨となる前提**（変更するときはここに戻ること）

| 前提 | 理由 |
|---|---|
| 感度はリミッタ段が決める。RFアンプではない | 10.7 MHz で 70 dB を稼ぐのはここだけ |
| 検波出力に**デエンファシスも 15 kHz LPF も入れない** | 19 kHz パイロットと 38 kHz 副搬送波を通す必要がある |
| ギルバートセルのスイッチング閾値は ±100 mV | 上段・下段の駆動振幅の下限を決める |
| Cc（1 pF）は**必ず検波基板側**に実装 | 配線容量がタンク側に乗るのは同調で吸収できるが、Cc を向こう側に置くと 1 pF が配線容量に埋もれる |
| AFC は不採用 | 設計初期に除外 |

## 4. 調整手順

**専用基板でも同じ手順が必要。** 順番を飛ばさないこと。

### 必要な機材

- DMM（DC 電圧）
- オシロスコープまたは Analog Discovery 3（×10 プローブ 2本）
- 信号源（AD3 の Wavegen で可）
- L メータ（IFT 調整用）
- 非金属の調整ドライバ

---

### STEP 0 — DC 動作点の確認（無信号）

電源を入れ、**信号を一切加えずに**第3章の表と照合する。

**リミッタ側**
1. VCC 5.00 / VK 4.80（段ごと）/ VB 2.12
2. **BA・BB を全8点測定。1.98〜2.00 V に揃っていること**
3. 共通エミッタ E が全段 1.28〜1.30 V
4. 総電流 35 mA 前後

**検波側**
5. VBU 2.36 / VBL 1.59
6. BU1 = BU2（±10 mV）、BL1 = BL2（±10 mV）
7. ET 0.89 / CL1 = CL2（±10 mV）
8. **OA と OB の差は ±300 mV 以内**（±50 mV は厳しすぎる。ディスクリートの Vbe ばらつき ±5 mV で 300 mV 動く）
9. QD = 0 V、SF 0.6〜0.7 V、AFE ≒ OB − 0.62 V

> **BA が 1.5〜1.6 V まで下がっている段があれば、その段は発振している。**
> 第5章へ。

---

### STEP 1 — リミッタ単体の確認

検波基板を外し、リミッタ出力を 330Ω で終端した状態で行う。

1. 入力を 330Ω で終端し、**無信号のまま**各段のコレクタを観測
   - 1〜3段目：ランダムノイズのみ
   - 4段目：ランダムノイズのみ（正弦波が見えたら発振）
2. セラミックフィルタ経由で 10.7 MHz を入力し、振幅を変えて S4A を観測
   - 入力 24 dB 変化に対し出力変化が 1 dB 以内ならリミッティング良好
3. **キャプチャ閾値の測定**
   - 高利得リミッタは自分のノイズで飽和するため、「出力が 3 dB 下がる点」という古典的な閾値測定は**原理的に不可能**
   - 代わりに**入力を絞っていき、出力の周波数が 10.700 MHz に追随しなくなる点**を読む
   - 目標：0.6 mVrms 以下

---

### STEP 2 — IFT タンクの同調

**検波基板を単体で、外部差動信号源で駆動して行う。**

#### 接続

| 測定点 | 器材 | 設定 |
|---|---|---|
| W1 → S4A 端子 | AWG | **0Ω ジャンパ**（50Ω ではない） |
| W2 → S4B 端子 | AWG | **W1 と同一種・同一長のケーブル** |
| C1 → RQ1 の**左端** | ×10 プローブ | AC 結合 |
| C2 → RQ1 の**右端**（= BL1） | ×10 プローブ | AC 結合 |
| AFE | **DMM（DC）** | |
| GND | 基板の GND バス① | |

Wavegen：**Synchronized モード**、W1 = Sine 10.700 MHz / Amplitude 1.5 V（= 3 Vpp）/ Phase 0°、W2 = 同じ / Phase 180°

> **タンク（QD）を直接プローブしてはいけない。**
> ×10 プローブの 15 pF が実効 100 pF のタンクに乗り、共振点が数 % 動く。
> ×1 プローブ（24 pF）なら壊滅的。**ソースフォロアはこのためにある。**

> RQ1 の左端は結合コンデンサ CQ(1000p、10.7 MHz で 15Ω)の先なので、
> 交流的には J17 のソースと同じ。DC だけが違う（左端 1.53 V / ソース 0.66 V）。

#### 手順

1. AWG を **10.700 MHz 固定**にする
2. **C1 の Peak2Peak が最大になるようコアを回す**
   - 並列タンクは |Z| 最大点と位相 0° 点が一致するので、振幅ピーク = 検波中心
   - 周波数を振り直す必要はない
3. 期待値

| | 期待値 | 実測例 |
|---|---|---|
| C1（SF） | 366 mVpp | 317 |
| C2（BL1） | 239 mVpp | 213 |
| **C2 / C1 比** | **0.653** | **0.672** |
| AFE | 2.78 V | 2.760 |

**比が合っていることが絶対値より重要。** 比が合えばソースフォロアの動作点も下段のベース入力インピーダンスも設計通り。絶対値の 10 % 程度の差は駆動振幅の校正誤差の範囲。

4. 調整後、**コアをロウかワニスで固定**する

#### 判定

| 症状 | 原因 |
|---|---|
| C1 が期待値の 1/3 以下 | タンクの Q が低い、Cc(1p) の付け間違い |
| C2 < 200 mVpp かつ C2/C1 比が正常 | 問題なし（後述） |
| C2 が C1 より大きい | C2 が信号ではなくノイズを見ている。SF ジャンパか RQ1 の接続不良 |
| 周波数計が 10.7 MHz を示さない | 同じく信号が届いていない |

> **RQ1 について**：設計メモには「BL1 を 500〜700 mVpp に調整」とあるが、
> 実測 213 mVpp で直線性 1.0 % が出ている。下段が完全スイッチせず線形寄りで
> 動いているが、リミッタが AM を除去済み（24 dB → 0.3 dB）なので実害がない。
> **470Ω のままでよい。** 下げる必要はない。

---

### STEP 3 — S カーブの確認（上段クアッドの検査）

**上段クアッド QU1〜QU4 の交差配線が正しいかは、これでしか判別できない。**
もし交差が誤っていれば位相検波器ではなく単なる差動増幅器になり、周波数を振っても AFE が動かない。

1. DMM を AFE に当てたまま、**W1・W2 の周波数を揃えて**振る
2. Synchronized モードでも、両チャンネルの `Output` 表示が同じ値か必ず確認する
3. 10.55〜10.90 MHz を記録し、第3.5節の表と照合

#### 判定

| 結果 | 判断 |
|---|---|
| 10.55→10.90 で 1.4 V 程度、単調増加 | **正常。上段クアッド OK** |
| ほとんど動かない（±100 mV 以内） | 上段クアッドの配線ミス |
| 動くが傾きが半分以下、裾が広い | コイルの無負荷 Q が低い。Cc を 1p→2.2p、または Rp を 4.7k→8.2k |
| 傾きの符号が逆 | 出力を OA から取っているか OB から取っているか（第9章参照）。不具合ではない |

**中心周波数の確認方法**：±75 kHz の2点の中点と、10.700 MHz での実測値を比較する。
差を感度（5.375 mV/kHz）で割ればズレが kHz で出る。

```
(2.368 + 3.164)/2 = 2.766 V   実測 10.700 MHz = 2.760 V
差 6 mV ÷ 5.375 mV/kHz = 1.1 kHz  →  中心 10.7011 MHz
```

---

### STEP 4 — 2基板の接続

1. **S4A / S4B をツイストペアで、5 cm 以内、基板を端どうしで並べて接続**
   - 3 Vpp が入力側の横を通る配置は厳禁。必要な結合はわずか 0.035 pF
   - 撚れば放射が打ち消し合い 20〜30 dB 稼げる
   - 10.7 MHz の波長は 28 m。5 cm は λ/560 なので完全な集中定数、整合は不要
2. GND は太く短く、信号対のすぐ横を通す
3. **接続後、リミッタ 4段ぶんの BA 電圧（8点）を再測定**
   - 3 Vpp の基板間配線は強力な加害者。ここは必ず確認する
4. タンクを再ピーク調整（配線容量がわずかに乗る）

---

### STEP 5 — 総合試験

AD3 Wavegen の **FM 変調機能**を使う。

```
搬送波 10.7 MHz / 偏移 ±75 kHz / 変調 1 kHz
→ セラミックフィルタ経由でリミッタ入力へ
→ AFE をオシロで観測
```

**1 kHz の正弦波が約 800 mVpp** で出れば、フロントエンド以外の全段が通ったことになる。
入力振幅を絞っていけばキャプチャ閾値も同時に測れる。

## 5. トラブルシューティング

### 5.1 発振（本プロジェクトで最大の難関）

#### 症状と診断

| 観測 | 意味 |
|---|---|
| ある段の BA だけ 1.5〜1.6 V（正常 1.99 V） | **その段でベース整流が起きている＝Class-C 動作＝発振** |
| Vbe が 0.25 V | **導通中の BJT では物理的に不可能**。完全に発振の指紋 |
| 共通エミッタ E が他段より高い | 同上 |

**定量化**：BA = VB − Ib × RGA なので、BA の低下からベース電流が逆算できる。
今回は 57 µA（正常時 13.5 µA）で、4倍以上の整流電流が流れていた。

#### 原因の切り分け（この順で）

1. **段を切り離して二分探索する**。コンデンサを外して段を分離し、どこから発振が始まるか
2. **迷結合バジェットと照合する**

| ループ | 発振に必要な結合容量 |
|---|---|
| 4段ループ | **0.035 pF** |
| 3段ループ | 0.208 pF |
| 2段ループ | 2.06 pF |
| 4段目単独 | 20.7 pF |

4段ループなら 0.035 pF —— 1 cm 以内を 5 cm 並走すれば 0.1〜0.3 pF に達する。
**単独段で発振するには 20 pF が必要**なので、単独発振はまず疑わなくてよい。

3. **グラウンドリターンを疑う**（今回の真因）
   - 電源GNDの基板への入口を**出力側の端**に移す
   - 1段目のGND（330Ω終端、CIB、RT、VK1 デカップリング）を**1点に集める**
   - 1段目はシングルエンド駆動なので、**IN B のGNDと RT のGNDの差がそのまま差動入力になる**
   - 76 dB の利得に対し、必要な帰還はわずか **0.2 mV**

#### 誤った切り分け（実際にやってしまった失敗）

> **「200 mV/div でバイアス経路を見たがノイズも発振も見えない → バイアス経路は白」は誤り。**
> 76 dB の利得に対して必要な帰還は 0.2 mV。そのレンジでは絶対に見えない。
> この誤判断で伝導結合の仮説を一度消してしまい、遠回りした。

#### 副次的な現象

- **スケッギング（間欠発振）**：CIA 100p × RGA 10k = 1 µs → 約 1 MHz でゲーティング
- **抵抗テールの効果**：オーバードライブ時はエミッタノードが入力に追従するため、**瞬時のテール電流が静止電流を超える**。出力が I_static × RC を超えるのは異常ではない

### 5.2 外来ノイズ

| 確認方法 | 判定 |
|---|---|
| 入力終端抵抗に手を近づけてノイズが増える | 外来ノイズ確定 |
| プローブ先端をグラウンドクリップに接続してほぼゼロ | 測定系の床ではない |
| 缶などで覆うとノイズが減る | シールド不足 |

**セラミックフィルタより後ろで拾ったノイズは濾過されない。** OUT ピン → 330Ω → CIA を最短で詰めること。

### 5.3 パルス性ノイズの測定に関する注意

インパルス性ノイズは単発測定ではばらつきが大きく、**2〜3 dB 程度の変化は測定できない**。
「ダンピング抵抗を 1k→220Ω に変えて 2.5 dB の変化を見る」という実験は、
分散に埋もれて何も分からない。設計してはいけない実験の典型。

## 6. 測定系の落とし穴

今回、**回路の問題より測定系の問題で時間を使った**。ここは繰り返し読む価値がある。

### 6.1 プローブ

| 項目 | 内容 |
|---|---|
| **タンクを直接測らない** | ×10 の 15 pF で共振が数 % ずれる。ソースフォロア経由で見る |

### 6.2 Analog Discovery 3

| 設定 | 値 | 理由 |
|---|---|---|
| W1/W2 ジャンパ | **0Ω** | 負荷が 6 kΩ なので源インピーダンスは無関係。設定値＝ノード電圧になる |

シャントのままだとフィルタが必要とする信号源インピーダンスが短絡される。

## 7. IFT の製作

### 7.1 実績

| | 値 |
|---|---|
| 巻数 | 18T |
| 調整後インダクタンス | 2.21 µH（L メータで実測して調整） |
| 同調容量 | CP 100p（＋基板の浮遊容量） |
| 結果 | コアが **2 mm 外に出た** |

共振周波数の検算：

```
C = 1 / (ω²L) = 1 / ((2π × 10.7e6)² × 2.21e-6) = 100.1 pF
```

CP = 100p とぴったり。浮遊容量はほぼ効いていない。

### 7.2 次回への改善

**17T を推奨。**

インダクタンスは巻数の2乗に比例するので、17T なら同じコア位置で

```
2.21 µH × (17/18)² = 1.97 µH   （−10.8 %）
```

これを 2.21 µH に戻すぶんコアが奥に入るため、2 mm の出っ張りは解消する見込み。
16T（−21 %）だと逆側の調整代を使い切る恐れがあるので避ける。

### 7.3 コアの固定

検波中心を ±30 kHz 以内に保つための要求値：

```
Δf/f = 30 kHz / 10.7 MHz = 0.28 %   →   ΔL/L = 0.56 %
```

コアが出た状態で振動すればこの程度は簡単に超える。
**調整後にロウまたはワニスで固定すること**（市販 IFT と同じ処置）。

なお、中心がずれた場合の DC オフセットは出力の COUT 10µF で除去されるため、
実害は S カーブの非対称性による歪みの増加。±30 kHz なら実用上問題にならない。

## 8. 専用基板への申し送り

### 8.1 万能基板版で判明した修正点（必ず反映すること）

1. **CLA / CLB（上段コレクタの 1000p）は GND バスへ。VCC ではない。**
   RTG と同じ GND バスに戻すこと
2. **SOT-23 は鏡面配置禁止。**
   全個体で `sign((B→E) × (B→C))` が一致していることを機械的に検算する
3. **出力は OA / OB のどちらから取るかで S カーブの極性が反転する**
   万能基板版は OB から取っており、周波数上昇で AFE が上がる。不具合ではないが認識しておくこと

### 8.2 GND 構造

**ベタGND ＋ 縫いビア。ガードリング＋一点接地は採用しない。**

理由：今回の発振は電界結合ではなく、**共通リターン経路のインダクタンスを介した伝導結合**だった。
一点接地は島のリターン電流を接続点まで迂回させるため、ループ面積とインダクタンスを**増やす**。
ベタGNDならリターン電流は自動的に信号トレース直下（最小インダクタンス経路）を流れる。

縫いビア：
- **層を変える信号ビアの隣には必ず GND ビアを添える**（最重要）
- それ以外は 5〜10 mm 間隔で十分
- 10.7 MHz は λ = 28 m なので波長基準の間隔規定は意味がない

ベタGNDより効く3点：
1. **4段を一直線に配置。入力を一方の端、出力を反対の端に。折り返さない**
2. **電源・GND の基板への入口を出力側の端にする**（万能基板で実証済み）
3. **1段目の入力ノードの面積を最小に**

セクション分離をしたい場合、正しい形は**ベタを切ることではなく、1段目領域と4段目領域の間にビアフェンス（縫いビアの列）を立てること**。

### 8.3 将来のオプション用パターン

**段間セラミックフィルタ（2段目↔3段目）**

現状は不要だが、パッドと 0Ω バイパスパターンを用意しておく。

- 差動を維持するには**フィルタ2個**（各脚に1個）が必要
- 位相不整合の影響は小さい：Δφ = 10° でも同相成分は −21 dB、次段の CMRR 28 dB を通れば −49 dB
- **入力側は好都合**：コレクタ負荷 330Ω がそのまま所要の信号源インピーダンス。
  ただし**ピーキングコイル 6.8 µH は外すこと**（+j457Ω で 564Ω∠54° になってしまう）
- **出力側が問題**：3段目のベース入力インピーダンスは ngspice 実測で

```
Zbase @ 10.7 MHz = 188Ω ∠−74.7°  =  49.6 − j181 Ω
```

  実部わずか 50Ω、大部分が容量性。しかもリミット中はベース整流で変動する。
  → **RBA を 47Ω → 270Ω、CIA を 100p → 1000p** に変更が必要

- **代償は 1箇所あたり約 14 dB**（エミッタフォロアを挟めば 8 dB）。**5段目の追加が必要**
- 効果は選択度（隣接チャネル ±300 kHz で 25 dB → 50 dB 級）。
  副次効果として帯域外利得（2.61 MHz の 75.9 dB）を潰すので発振耐性も上がる

したがって基板には **RBA を 47Ω / 270Ω で選べる**ようにしておくと後戻りが効く。

**シールド**

1〜2段目の上に小さなシールドケースを載せるのが費用対効果が最も高い
（万能基板では空き缶で効果を確認済み）。フロントエンドの手の容量によるドリフトにも効く。

## 9. 設計判断とその根拠

**「なぜこの定数なのか」を忘れたときのために。**

### 9.1 カップリング容量が 100p と 1000p で違う理由

- **リミッタ段間 100p**：次段のベースインピーダンスが低い（Cπ 85p ＋ ミラー 220p で約 50Ω）ため、
  100p（10.7 MHz で 149Ω）では無視できない損失が出る。だが結合を強くしすぎると
  段間の低周波結合が増え、スケッギングの時定数にも効く
- **4段目→ギルバート 1000p**：上段の分圧が 5.6k+1k と高インピーダンスなので、
  結合容量の損失を無視できる値にしてある

### 9.2 テールが抵抗（150Ω）で電流源でない理由

5 V ではカレントミラーを積む電圧余裕がない。
副作用として、**オーバードライブ時にエミッタノードが入力に追従し、瞬時テール電流が静止電流を超える**。
出力振幅が I_static × RC を超えても異常ではない。

### 9.3 5 V の縦積み（最も苦しい部分）

ギルバートセルの電位スタック：

```
ET 0.891 → CL1 1.736 → OA 3.42    残り headroom 1.6 V
```

Vbe を2段積み、テール抵抗で 0.89 V を払ったうえで 800 mVpp を振らせている。
VBU 2.36 / VBL 1.59 という分圧の余裕のなさがそのまま設計難易度になっている。
**この2つのバイアス電圧は迂闊に動かさないこと。**

リミッタ側もコレクタが 1.7〜4.7 V を振っており、飽和の縁で動作している。

### 9.4 Rp（タンクのダンピング抵抗）の選択

| Rp | ±75 kHz 出力 | THD | ±37.5 kHz |
|---|---|---|---|
| 8.2k | 1075 mVpp | 5.3 % | 552 mVpp |
| **4.7k** | **737 mVpp** | **1.8 %** | **377 mVpp** ← 採用 |
| 2.7k | 467 mVpp | 0.3 % | 234 mVpp |

実測は 796 mVpp / 直線性 1.0 % で、予測を上回った。

### 9.5 検波器の位相関係

上段は限界まで振り切った（ハードスイッチ）信号、下段はタンクを通した位相シフト信号。
**直交（90°）が取れているとき OA = OB となり、AFE は無信号時とほぼ同じ値**になる。
これが同調点の判定基準。実測 2.760 V（無信号 2.660 V）で、+98 mV しか動いていない＝バランスが取れている。

## 11. MPX 出力段 rev.E（2026-09-23 改訂）

### 11.1 発覚した設計欠陥：L−R が −3.93 dB 落ちていた

検波後 LPF の定数（CLA/CLB/CF1 = 1000 pF）が**コンポジット帯域の上端を削っていました。**

| 周波数 | 1 kHz 基準 |
|---|---|
| 19 kHz（パイロット） | −0.74 dB |
| 23 kHz（L−R 下側波帯） | −1.05 dB |
| 38 kHz（副搬送波） | −2.43 dB |
| **53 kHz（L−R 上側波帯）** | **−3.93 dB** |

L−R が L+R に対して X dB 落ちると、セパレーションは `20·log((1+k)/(1−k))`、k = 10^(−X/20) で頭打ちになります。

```
−3.93 dB  →  セパレーション上限 13.1 dB
```

**ステレオがまともに分離しない原因はここでした。**

### 11.2 対策：CLA / CLB / CF1 を 220 pF に

| 定数 | 19k | 38k | 53k | 21.4 MHz 減衰 | セパレーション上限 |
|---|---|---|---|---|---|
| 1000p（旧） | −0.74 | −2.43 | −3.93 | −88.7 dB | **13.1 dB** |
| 470p | −0.18 | −0.67 | −1.22 | −75.6 dB | 23.1 dB |
| **220p（採用）** | **−0.04** | **−0.16** | **−0.30** | **−62.6 dB** | **35.2 dB** |
| 100p | −0.01 | −0.03 | −0.07 | −49.2 dB | 48.3 dB |

220 pF なら 21.4 MHz（2×IF）の除去も −62.6 dB 残るので実用上十分です。

> **2026-09-26 訂正**：上の「セパレーション上限」は、L−R 全体が 53 kHz の減衰を受けるとした最悪値で、
> **マトリクス（RV2）で補正しない場合**の数字です。両側波帯の平均と、RV2 を 1 kHz で合わせることを考慮して計算し直すと、
> 220 pF では **補正なしで約 41 dB、1 kHz で補正後は 15 kHz でも約 58 dB** になります（`netlist/lpfchk.cir` と同じ回路、
> ステレオデコーダの 38 kHz がこの LPF を通ったパイロットから作られる前提＝V4 方式）。
> **検波後 LPF は受信機全体のセパレーションのボトルネックではありません。**


### 11.3 非反転2段利得段（Q17 / Q18）

> **2026-09-26 注記：実機には実装していません**（実機は Q16 エミッタフォロア1段のまま、MPX OUT は 100 % 変調で約 0.8 Vpp）。
> 次期デコーダ V4 では、利得は **MPX 基板の U2C（オペアンプ）で 2.5 倍**取ります（`MPX_V4_HANDOFF.md` D9）。この節は設計記録として残します。

MPX デコーダのコンポジット入力を強化するための追加段。**低周波アンプを通すと L−R が落ちるので、広帯域の専用段を置きます。**

| 部品 | 値 |
|---|---|
| C1 / C2 | 1 µF（段間結合） |
| R1A / R2A | 100 k |
| R1B / R2B | 47 k |
| R1C / R2C | 2.2 k |
| R1E | 1.2 k |
| R2E | 1.1 k |
| Q17 / Q18 | MMBT3904 |

**検証値**

| 項目 | 値 |

### 11.4 利得の上限（5 V の物理限界）

エミッタ抵抗を未バイパスにした CE 段では、コレクタの負側振幅が**エミッタ自身の振れ**に食われます。

```
コレクタ下限 > Ve0 + Vin振幅 + Vce(sat)
```

このため 796 mVpp のコンポジットを 5 V で扱う上限は **約 3〜4 倍**です。
「数十倍」が必要ならスイッチング復調器の**後**（L/R 各チャンネル）に置くしかありません。

### 11.5 極性について

2段 CE なので**非反転**です。1段（反転）でも L/R は入れ替わりませんが（両チャンネルとも極性反転するだけ）、
**パイロット枝を利得段の後ろに移すと L と R が入れ替わります。** 分岐点は動かさないこと。

### 11.6 STEP 6：コンポジット帯域の確認（調整手順に追加）

**この検査が無かったために −3.93 dB の欠陥を見逃しました。** 第4章の STEP 3 の後に実施してください。

S カーブの測定（STEP 3）は**搬送波の周波数をずらして DC 出力を見る**試験なので、
**「変調周波数に対する応答」＝コンポジット帯域の平坦度は一切測れていません。**
L−R は 23〜53 kHz に乗るので、ここが落ちているとステレオ分離が崩れます。

#### 手順

AD3 の Wavegen の **FM 変調**を使います。

```
搬送波 10.700 MHz ／ 偏移 ±10 kHz（小さめでよい）
変調周波数を 1 kHz → 60 kHz までスイープ
→ MPX OUT の振幅を測る（オシロまたは AD3 の Scope）
```

偏移を小さくするのは、変調指数を下げて側波帯を搬送波 ±(変調周波数) の1組に絞るためです。
セラミックフィルタ（帯域 ±115 kHz）と IFT タンク（帯域 ±490 kHz）はこの範囲では効きません。
**測っているのは検波後 LPF の特性そのものです。**

#### 判定

| 変調周波数 | 1000p（旧） | 220p（修正後） |
|---|---|---|
| 1 kHz | 0 dB（基準） | 0 dB |
| 19 kHz | −0.74 dB | −0.04 dB |
| 38 kHz | −2.43 dB | −0.16 dB |
| **53 kHz** | **−3.93 dB** | **−0.30 dB** |

**53 kHz が −0.5 dB 以内なら合格**（セパレーション上限 30 dB 以上）。
−2 dB を超えていたら LPF の定数を見直してください。

> **教訓**：S カーブが完璧でも、コンポジット帯域が平坦とは限りません。
> FM 検波器の試験は「搬送波をずらす」と「変調周波数を変える」の**2軸**で行う必要があります。
