## 1. 全体構成

```
アンテナ
  │  RSRC 75Ω（源抵抗）
  ├─ C1 1000p ─→ J1 ソース（ゲート接地 RF アンプ）
  │                 │ R1 100Ω
  │              J1 ドレイン = N006
  │                 │
  │            ┌────┴──── RF タンク ──────┐
  │            │  L1 82nH                  │
  │            │  CVRF 10–30p（バリコン1連）│  ← Cb 1000p 経由で GND
  │            │  C3A 33p ─ TAP ─ C3B 39p  │  ← 容量タップ
  │            └────┬──────────────────────┘
  │                TAP ─ C4 1000p ─→ RF-IN（J3 ゲート）
  │
  │   J2 コルピッツ局発             J4 LO バッファ
  │   L2 56nH // C5 11p // CVLO      （ソースフォロワ）
  │   C6 27p / C7 27p 帰還分圧   →   C16 1000p → J4 → C9 1000p
  │                                          ↓
  └──────────────────→ J3 ソース注入ミキサ ←┘
                            │ ドレイン N003
                         IFT L3 4.7µH // C8 47p
                            │ k = 0.71（実測）
                         L4 0.65µH（実測）→ IF-OUT ─ R8 330Ω
                                                    │
                                    → セラミックフィルタ → IF ストリップへ
```

**信号の流れは左→右の一方通行**。基板中央に電源＋GND のガードバンドを置き、
上半分（RF 系）と下半分（LO 系）を分離します。

## 2. 回路定数（rev3）

### 2.1 RF 増幅段（J1・ゲート接地）

| 部品 | 値 | 備考 |
|---|---|---|
| J1 | 2SK3557 | Id 3.3 mA / gm 18 mS |
| RSRC | 75 Ω | アンテナ側の源抵抗（実機ではアンテナそのもの） |
| C1 | 1000p | アンテナ結合 |
| R1 | 100 Ω | ソース（＝入力）。ゲート接地なので入力抵抗は 1/gm ≒ 56Ω と並列 |
| R2 | 100k | ゲートバイアス |
| C2 | 1000p | ゲート接地用バイパス |

**ゲート接地を選んだ理由**：入力インピーダンスが低く安定、逆方向アイソレーションが高い。
実測でも局発のアンテナ側漏れは **2 µV** とほぼゼロでした。

### 2.2 RF タンク（容量タップ付き）

| 部品 | 値 | 備考 |
|---|---|---|
| L1 | **82 nH** / Rser 0.9 | 空芯 4T・巻き幅 3.3 mm（内径 5 mm） |
| CVRF | 10–30 p | ポリバリコン第1連 |
| Cb | **1000 p** | **バリコンと直列。ロータを実 GND に落とすため** |
| C3A | **33 p** | 容量タップ（N006 – TAP） |
| C3B | **39 p** | 容量タップ（TAP – N001） |
| CSTR1 | 3 p | 配線ストレー想定値（実装で調整） |

C3A/C3B の直列合成は 17.9 pF で、これが RF タンク容量の一部になります。

> **Cb が必要な理由**：L1 の冷側 N001 は「デカップルされた +5V」、ホット側 N006 は J1 のドレインで
> こちらも DC +5V。**どちら側に繋いでもバリコンに +5V が掛かり、ロータをシャーシ GND に落とせません。**
> ロータが浮くと手を近づけるだけで同調がふらつきます。
> 向きは **N006 → Cb → ステータ／ロータ → GND**。逆向きでは意味がありません。
>
> Cb 1000p は 10–30 pF と直列で 9.90–29.13 pF になり、容量比が 3.0 → 2.94 に変わるだけ。
> L1 = 82 nH のまま成立します（並列パディングが 23.9 → 24.3 pF に変わる程度）。

### 2.3 局部発振（J2・コルピッツ）

| 部品 | 値 | 備考 |
|---|---|---|
| J2 | 2SK3557 | **Id 0.28 mA**（実測 Vs 0.624 V ÷ 2.2k）／ gm 5.2 mS |
| L2 | **56 nH** / Rser 0.6 | 空芯 3T・巻き幅 2.3 mm |
| C5 | **11 p** | パディング |
| CVLO | 10–30 p | ポリバリコン第2連。**両端とも実 GND でよい**（DC が掛からない） |
| C6 / C7 | 27 p / 27 p | 帰還分圧比 1:1。起動余裕十分 |
| R5 | 2.2 k | ソース。**実測で確定**（第11.1章） |
| CSTR2 | 3 p | 配線ストレー想定値 |

LO 周波数 = 受信周波数 + 10.7 MHz。**86.7 – 105.7 MHz** をカバーします。

### 2.4 LO バッファ（J4・ソースフォロワ）

| 部品 | 値 | 備考 |
|---|---|---|
| J4 | 2SK3557 | Id 1.05 mA。**コイル不要** |
| C16 | 1000 p | 入力結合。**N011（C6/C7 の分圧点）から取る** |
| R9 | 100 k | ゲートバイアス |
| R10 | 470 Ω | ソース |
| C9 | 1000 p | ミキサソースへの出力結合 |

**入力を N011 から取る理由**：タンク（N009）から取ると J4 の入力容量 約 10 pF が
タンクに直接乗り、**パディング予算（31 pF）の 1/3 を食ったうえに周波数が引っ張られます。**
N011 は C6/C7 の分圧点で既に低インピーダンスなので、ここから取ればタンクへの影響が小さく済みます。

**バッファが必要な理由**：元設計の C9 = 5p 直結では 90 MHz で 379 Ω。
ミキサソースの入力抵抗 1/gm ≒ 134 Ω に対して分圧損が大きく LO が届きません。
かといって C9 を大きくすると**発振器を引っ張って止まります**（実測：R7 = 680Ω で C9 = 22p にすると発振停止）。
バッファを挟むと両立します。**実測でミキサソースの LO 振幅が 111 mV → 371 mV に改善。**

### 2.5 ミキサ（J3・ソース注入）

| 部品 | 値 | 備考 |
|---|---|---|
| J3 | 2SK3557 | Id 0.55 mA / gm 7.5 mS |
| C4 | **1000 p** | RF 入力結合（元は 5p。第3章参照） |
| R6 | 100 k | ゲートバイアス |
| R7 | 1 k | ソース。680Ω〜2.2k で大差なし |

**LO 振幅には上限があります。** 変換利得は gc = β·Vlo(gs) なので大きいほど有利ですが、
**|Vp| = 0.7 V を超えるとゲート順方向導通やカットオフでの波形クリップが増えてスプリアスが悪化します。**
rev3 のソース LO 370 mV は、バイアス −0.55 V と合わせてちょうど良いところに乗っています。

## 3. 初期設計の問題と修正の経緯

**この章が、この資料で最も価値のある部分です。**
元の設計（別 AI が作成）は LTspice 上で「80 MHz を受信できている」ように見えていましたが、
検証の結果**成立していませんでした。**

### 3.1 「受信できている」は 73.55 MHz の寄生発振だった

`.tran` を 2 µs → 40 µs に伸ばすと、J1 ドレインに **73.55 MHz / 4.3 Vpk** の自己発振が立ち上がります（5 V 電源に対してクリップ）。

- V(rf-in) が ±180 mV まで育っていたのは 10 µV 入力の増幅ではない ── **JFET 1段で 85 dB は不可能**
- IF-OUT に出ていた成分は 85.75 − 73.56 = **12.19 MHz の偽 IF**
- FFT の 10 MHz 付近のなだらかな山は IF タンクのリンギング（**輪郭が丸いのがその証拠**）

> **教訓**：`.tran` の時間が短いと発振は見えません。
> 高周波回路のシミュレーションでは、**定常状態に達するまで走らせてから FFT を取る**こと。
> rev3 では `.tran 0 40u 0 200p`、FFT は定常部（24–40 µs）のみを選択しています。

### 3.2 寄生発振の原因：C4 = 5p

RF タンクが J3 のゲートに**高インピーダンスでぶら下がっていた**ことが原因でした。

```
J3 ゲート → Cgs 7.1p → J3 ソース（R7 1k）が帰還路になり、
J3 ＋ L1/C3 が意図しない Colpitts を構成する
```

**切り分けの実験**：

| 操作 | 結果 |
|---|---|
| J2（本来の局発）を外す | **発振は継続** → 局発が原因ではない |
| J3（ミキサ）を外す | **発振が消える** → J3 が発振器 |
| C4 を 5p → 0.05p | **発振が消える** → 結合が原因 |

**対策**：C3 を **C3A 33p / C3B 39p の容量タップに分割**し、
C4 を **5p → 1000p** に変更してゲートを低インピーダンスで駆動する。

これで **2つの問題が同時に解決**しました。

### 3.3 変換利得が −34 dB だった理由

C4 = 5p と C9 = 5p のせいで、**ソースの LO が Cgs 経由でゲートにも乗り、vgs の LO 成分が打ち消されていました。**

ミキサ単体テストでゲートを低 Z 駆動にすると **+21 dB 改善**。
容量タップ化はここにも効いています。

### 3.4 Rser = 1m が非物理的だった

元ネットリストの `Rser=1m` は L1 の Q が **110,000** に相当します。実物は Q = 40〜80。

Q をスイープすると **Q > 92 で必ず発振**するので、
「シミュレーションでは動くが実機では発振する」という最悪のパターンでした。

rev3 では L1 Rser = 0.9、L2 Rser = 0.6、L3 Rser = 3（Q = 105）と現実値に修正しています。

> **教訓**：**インダクタの Rser を省略しない。** 省略＝理想コイル＝無限大の Q です。
> これは回路が動くかどうかの判定を根本から狂わせます。

### 3.5 その他の修正

| 項目 | 元 | rev3 | 理由 |
|---|---|---|---|
| C5 | 18 p | **11 p** | LO が 85.75 MHz だった。80 MHz 受信には 90.7 MHz が必要 |
| L1 | 220 n | **82 n** | 10–30 pF バリコンで 76–95 MHz をカバーするため |
| L2 | 100 n | **56 n** | 同上（LO 86.7–105.7 MHz） |
| 可変素子 | なし | CVRF / CVLO | **元設計には 76–95 MHz を可変する素子が無かった** |
| V2 | 10 µV | 1 mV | 10 µV は数値ノイズに埋もれる |
| RSRC | なし | 75 Ω | 理想電圧源では入力整合が評価できない |

### 3.6 電源デカップリングの 0.87 MHz 共振（実在します）

検証中にフェライトビーズを理想インダクタ（350 nH）に置き換えたところ、
ミキサドレインに **4 Vp-p の 0.87 MHz 発振**が出ました。
350 nH と 0.1 µF の共振点がちょうど **851 kHz** です。

MPZ1608S601 は損失で自然に減衰させるので問題ありませんが、
**ここを普通のインダクタに置き換えると低周波発振します。ビーズのままにしてください。**

## 4. 性能（シミュレーション実測値）

### 4.1 バリコンによるトラッキング

| バリコン | 受信 f | LO | IF 誤差 | 総合利得 | 寄生発振 |
|---|---|---|---|---|---|
| 30 pF | 75.70 MHz | 86.19 MHz | −0.21 MHz | +8.42 dB | なし |
| 24 pF | 80.00 MHz | 90.75 MHz | +0.05 MHz | +8.56 dB | なし |
| 15 pF | 88.50 MHz | 99.25 MHz | +0.05 MHz | +10.71 dB | なし |
| 10 pF | 95.30 MHz | 105.12 MHz | −0.87 MHz | +11.15 dB | なし |

低い側で利得が 2 dB ほど落ちているのは、Cb でタンク容量が少し動いて
RF タンクの同調が数百 kHz ずれているためです。**実機では RF 側トリマで合わせれば戻ります。**

帯域端で IF 誤差が ±0.2〜0.9 MHz 出ますが、これは**単連トラッキングの限界**です。
IF の帯域（セラミックフィルタ 230 kHz 程度）を超えるので、
**帯域端では RF 側を少しずらして合わせる**運用になります。

### 4.2 IF-OUT に現れる成分（実測 L4 = 0.65 µH / k = 0.71 を反映）

| 成分 | 振幅 |
|---|---|
| **10.7 MHz（IF）** | **2.10 mV** |
| 局発 95 MHz の漏れ | **4.69 mV ← IF より 7 dB 大きい** |
| 受信周波数の漏れ | 0.18 mV |
| 合成 pk-pk | 14.0 mV |

アンテナ入力レベル別（局発漏れは入力によらず一定なので、これがフロアになります）：

| アンテナ入力 | IF (10.7 MHz) | 局発漏れ | 合成 pk-pk |
|---|---|---|---|
| 100 µV | 0.22 mV | 4.77 mV | 10.1 mV |

| 1 mV | 2.15 mV | 4.77 mV | 14.1 mV |
| 3 mV | 6.46 mV | 4.77 mV | 22.8 mV |

> **局発漏れは後段のセラミックフィルタ（SFELF10M7GA00）で除去されます。**
> IFT 自体も 90.7 MHz で 39 dB 落としています。**IF ストリップには影響しません。**
> 問題になるのは**調整時にオシロで見るとき**だけです（第9章）。

### 4.3 システム全体の感度

IF ストリップのキャプチャ閾値は **0.37 mVrms**（`HANDBOOK.md` 参照）。
フロントエンドの総合利得を +8.5〜+17.8 dB とすると、必要なアンテナ入力は

```
0.37 mVrms ÷ (2.7〜7.8倍) = 約 50〜140 µV
```

**実測のフロントエンド出力 50 mVrms** は、これを大きく上回っています（強い局での測定値と推定）。

## 5. コイルの製作

### 5.1 コアの使い分け（重要）

| コイル | コア |
|---|---|
| **L1 / L2** | **空芯、またはブラス／アルミコア** |
| **L3 / L4** | **フェライトコア（3.6φ × 8 mm）** |

> **L1/L2 に手持ちのフェライトコアを使わないでください。**
> 3.6φ × 8 mm のコアは 10.7 MHz 用の材質のはずで、**80〜105 MHz では損失が大きく Q が落ちます。**
> FM チューナの定番は真鍮／アルミのコア ── 磁性体ではなく**渦電流で L を「減らす」**タイプです。
> フェライトコアは L3/L4 用に取っておくのが正解です。

### 5.2 L1 / L2（空芯・内径 5 mm）

| コイル | 目標 | 巻数 | 巻き幅 |
|---|---|---|---|
| L1 | 82 nH | **4 T** | 約 3.3 mm |
| L2 | 56 nH | **3 T** | 約 2.3 mm |

**3〜4 ターンしかないので、1 ターンの差が ±25 % 効きます。**
巻きを伸縮させれば ±20 % は動かせるので、**トリマと巻き間隔の両方で追い込む**前提でお考えください。

> **LC メータは 100 nH 以下では使えません。**（次節の実測参照）
> L1/L2 は**メータの読みを無視して、寸法で作ってください。**

### 5.3 LC メータの信頼性（実測）

| 巻数 | 実測 | 理論 | 実測/理論 |
|---|---|---|---|
| 3 T | 22 nH | 87 nH | **0.25** |
| 6 T | 100 nH | 267 nH | **0.37** |
| 20 T | 1450 nH | 1632 nH | **0.89** |

**L 値が小さいほど誤差が大きく、大きくなるほど消える** ── LC メータの典型的な挙動です。
µH レンジの読みは信頼できます。

**コア効果**：20 T で コア全挿入 4.00 µH ／ 全抜き 1.45 µH → **2.76 倍**

### 5.4 L3 の巻数設計

| 巻数 | 長さ | コア覆い率 | 全挿入 | 全抜き | 4.7 µH になるコア位置 |
|---|---|---|---|---|---|
| 20 T | 4.2 mm | 52 % | 4.00 µH | 1.45 µH | **到達不可** |
| 22 T | 4.6 mm | 58 % | 4.70–4.89 | 1.7 | 94–100 %（余裕なし） |
| 24 T | 5.0 mm | 63 % | 5.45–5.87 | 2.0 | 69–78 % |
| **27 T** | **5.7 mm** | **71 %** | **6.7–7.5** | **2.4–2.7** | **41–54 %（ほぼ中央）** |
| 30 T | 6.3 mm | 79 % | 8.0–9.4 | 2.9–3.4 | 22–36 % |

**推奨：L3 = 27 T / L4 = 9 T**（巻数比 3:1）

**中央に置きたい理由**：C8 の容量誤差（±5 %）と実装の浮遊容量（47 p に対し ±4 % 程度）で
共振点が ±10 % 動くため、**L で ±20 % の調整余地が欲しい**からです。
27 T なら 2.4〜7.5 µH の範囲があるので余裕で吸収できます。

24 T : 8 T でも到達はしますが、4.7 µH がコア 70〜78 % 挿入の位置になり、
上方向の余裕が 2 割程度しか残りません。

### 5.5 必要な線の長さ（φ0.21 mm）

| | 巻線部分 | リード（両端 15 mm） | 作業代（両端 30 mm） | **切り出し** |
|---|---|---|---|---|
| L3 27 T | 442 mm | +30 mm | +60 mm | **550 mm** |
| L4 9 T | 159 mm | +30 mm | +60 mm | **250 mm** |

L3：線の中心が描く円の直径 = ボビン外径 5 mm ＋ 線径 0.21 mm = 5.21 mm → 1 ターン 16.37 mm
L4：L3 の上に重ねるので 5.63 mm → 1 ターン 17.69 mm

> 0.21 mm は細いので、**作業代を両端 30 mm ずつ見ないと巻き終わりで引っ張って切れます。**
> また **27 T は巻き幅 5 mm には単層では入りません**（最小 5.7 mm、被覆込みなら 6.5 mm）。
> 8 mm のコアには収まります。5 mm 幅に押し込むと重ね巻きになり、自己容量が増えるのでお勧めしません。

**L4 は L3 の冷側に重ねて巻くと k が稼げます。** 実測 k = 0.71。

## 6. 電源デカップリング（実測で判明した本質）

### 6.1 ビーズは 1 個で十分 ── 効いているのはコンデンサ

基板配線 5 nH と実部品の ESL/ESR を入れた条件での実測：

| 構成 | LO 周波数 | N001 の LO 漏れ | N002 の LO 漏れ | RF タンク | IF 出力 | 総合利得 |
|---|---|---|---|---|---|---|
| (a) ビーズ 3 個 | 95.0625 MHz | 0.018 mV | 0.271 mV | 8.74 mV | 2.229 mV | +17.77 dB |
| **(b) ビーズ 1 個＋各段ローカルデカップ** | 95.0625 | **0.011** | **0.231** | **8.78** | **2.240** | **+17.81** |
| (c) ビーズ 1 個＋デカップも 1 か所だけ | 95.0625 | 0.317 | 1.449 | 6.46 | 1.804 | +15.99 |
| (d) ビーズ 2 個 | 95.0625 | 0.019 | 0.240 | 8.78 | 2.238 | +17.80 |

**(a) 3 個と (b) 1 個が完全に同等、むしろ (b) のほうがわずかに良い。**
一方 **(c) だけが明確に悪化**しています（RF タンク −2.6 dB、総合利得 −1.8 dB、N001 の LO 漏れが 29 倍）。

(b) と (c) の違いは**各段のドレイン／タンク冷側の直近に 0.1µ + 1000p を個別に置いたかどうかだけ**です。

> **段間分離を担っているのはローカルデカップリングコンデンサで、ビーズは分離にほとんど寄与していません。**
>
> ビーズの本当の役割は**基板の外との遮断**です：
> - 回路内の高周波が電源配線に漏れてアンテナ的に放射するのを止める
> - 外部（USB 電源やレギュレータ）から入るノイズを止める
> - 350 nH と 0.1 µF の共振（851 kHz）を損失で減衰させる

### 6.2 実装の推奨

1. **各段に 0.1µ + 1000p を個別に、ドレイン／タンク冷側の「直近」に置く** ← これが本体。省略不可
2. **ビーズの直後にもう 1 組**（0.1µ + 1000p）。(b) が (a) より良かった理由
3. **電源入口に 10 µF 程度のバルクを 1 個追加**。851 kHz 共振の減衰と低周波リザーバとして
4. **最優先は N001（RF タンクの冷側）。** ここは同調回路の AC 接地そのもの。
   N001 → C10/C11 → GND のループを基板上で最短に。
   **73.55 MHz の寄生発振もこのあたりのループが絡んでいました**

### 6.3 J2 / J4 のドレイン電源は共有でよい

| 構成 | J2 ドレインの LO リプル | LO@ミキサ | IF 出力 |
|---|---|---|---|
| 共有（ビーズ 1 個） | 0.698 mV | 111.0 mV | 2.304 mV |
| 分離（ビーズ 2 個） | 0.260 mV | 110.6 mV | 2.307 mV |
| 共有＋J4 に 100Ω&1000p の RC | 0.262 mV | 110.7 mV | 2.239 mV |

LO 周波数は 3 構成とも同一（FFT 分解能 62.5 kHz 以内で差なし）。
**分離すると J2 ドレインのリプルが −8.6 dB になりますが、5 V 電源上の 0.7 mV は元から十分小さく、効果が現れません。**

> **ただしレイアウトのほうが本質です。**
> この結果は C14/C15 がドレインピンの直近にある（ESL 0.6 nH）前提です。
> 実装でここが 5〜10 mm 離れると、配線インダクタンス 5〜10 nH が効いて
> 95 MHz でのインピーダンスが 0.3 Ω → 3〜6 Ω、**リプルは 10〜20 倍（7〜14 mV）**になります。
> そこまで来ると **LO の位相雑音として効いてきます。**

**優先順位**：
1. **C14/C15 を J2 と J4 の両ドレインの近くに置く** ← 一番効く
2. 両ドレインが離れるなら、遠い側に 1000p を 1 個追加（ビーズを増やすより安くて効果的）
3. ビーズ 2 個分離は機能上は不要

### 6.4 +5V 側よりグラウンド側

**J2 のソース抵抗 R5 と J4 のソース抵抗 R10 のグラウンドが長いパターンを共有すると、
電源経由よりそちらの共通インピーダンスのほうが結合経路になります。**

**R5・R10・C7 のグラウンドは 1 点に集めて、そこから太く落としてください。**

> これは IF ストリップで発振の真因だったのと**まったく同じ現象**です（`HANDBOOK.md` 第5章）。
> 共通リターンインピーダンスは、この種の回路で最も繰り返し現れる失敗モードです。

### 6.5 将来 IF 増幅段を追加するとき

**IF 段には別ビーズを推奨します。** IF 段は電流が増え、10.7 MHz を電源に撒くので、
そこがフロントエンドと共有だと局発や RF タンクに回り込む可能性があります。

## 7. レイアウト制約

**基板**：2.54 mm ユニバーサル基板 26 列 × 16 行（A〜P）、片面 GND プレーン
**実装**：1608（0603）＋ SOT-23 を片面に。部品面は**座標が見える面**（プレーン面に載せると半田がプレーンに触れて短絡の危険）

### 7.1 最大の制約：リード線のインダクタンス

**バリコンのリードとコイルのリードでは効き方が違います。**

- **バリコンのリード** → バリコンと**直列**に入るので、その枝の実効容量が増える
- **コイルのリード** → タンクの **L に直接足し算**される

**バリコンのリード長の影響（φ0.5 mm 単線、解析値）**

| リード長 | インダクタンス | 実効容量増加（Cv = 10p / 20p / 30p） |
|---|---|---|
| 5 mm | 2.9 nH | +1.3 % / +2.2 % / +2.7 % |
| **10 mm** | **7.3 nH** | **+3.3 % / +5.5 % / +6.9 %** |
| 15 mm | 12.1 nH | +5.5 % / +9.3 % / +11.8 % |
| 20 mm | 17.3 nH | +8.2 % / +14.1 % / +18.1 % |
| 30 mm | 28.6 nH | +14.4 % / +25.7 % / +33.8 % |

**増加率が容量値によって変わるためトラッキングが崩れます。**
20 mm だと帯域端で 1.5 MHz 程度の差が出ます。

> **両連ともリードは 10 mm 以内、かつ 2 本を同じ長さにしてください。これがフロアプラン最大の制約です。**

**コイルのリードの影響**

| コイル | 5 mm 余分な配線（3 nH）の影響 |
|---|---|
| L2 56 nH（LO） | L +5.4 % → 周波数 **−2.5 MHz** |
| L1 82 nH（RF） | L +3.7 % → 周波数 **−1.5 MHz** |

> **タンクのコンデンサはコイルのリードパッドに隣接必須。タンクのループ内にジャンパ線を入れられません。**
> これがコイル位置を決め、コイル位置が他すべてを決めます。

### 7.2 フロアプランの原則

1. **L1 と L2 を約 23 mm 離し、軸を直交させる**（L1 = 水平、L2 = 垂直）
   空芯コイル同士の結合で局発が RF タンクに回り込むのを抑える。
   **k = 0.02 だと 400 mV の局発が RF タンクに約 10 mV 誘起され、信号（約 9 mV）と同レベルになります**
2. **バリコンは左端中央にパネル取付**。第1連 → 上の RF タンク、第2連 → 下の LO タンク。
   リードを両方 10 mm 以内・同じ長さに
3. **アンテナは左上、IF 出力は右端**。信号が左→右に流れる一方通行
4. **中央帯（H・I 行）を電源＋GND ガードバンド**にして、上半分（RF）と下半分（LO）を分離
5. 右下は将来の IF 増幅段用に空けておく

### 7.3 2SK3557（SOT-23）の実装

**ピン配置（onsemi データシート）：ピン1 = ソース ／ ピン2 = ドレイン ／ ピン3 = ゲート**

- **ソースとドレインは同じ側**で 1.9 mm 間隔。2.54 mm のパッドに対して各 0.32 mm 内側に入るので、隣接パッド 2 つにそのまま乗る
- **ゲートは反対側の中心線上**なので、**必ずパッド間のギャップに落ちる**。パッド端まで約 0.5 mm。
  半田ブリッジか 2 mm 程度のジャンパが必要

**ゲートのブリッジが許容されるか**：

| 素子 | 判定 |
|---|---|
| J1（ゲート接地・C2 でバイパス） | 無害 |
| J4（バッファ入力） | 無害 |
| **J3 のゲート（RF-IN）** | **最短にすること** |
| **J2 のゲート（LO タンク）** | **最短にすること** |

> **SOT-23 は裏返して配置できません。** IF ストリップ側でも同じ誤りを繰り返しました。
> 配置前に全個体で `sign((B→E)×(B→C))`（JFET なら `sign((S→D)×(S→G))`）を検算してください。

### 7.4 GND 接続

裏面プレーンに半田ブリッジする対象：
R1、R2/C2、C5、C7、R5、R7、R8、R9、R10、デカップリング各 GND 側、L2 の下端、バリコンのロータ

**特に R5・R10・C7 の GND は 1 点に集めてから落としてください**（6.4 節）。

## 8. 未解決の課題

| 課題 | 現状 | 備考 |
|---|---|---|
| **イメージ抑圧** | **−19.4 dB** | 目標 60 dB に対して大幅に不足 |
| IF-OUT の LO 漏れ | 4.69 mV（IF の 7 dB 上） | セラミックフィルタで除去される |
| 帯域端のトラッキング誤差 | ±0.2〜0.9 MHz | 単連トラッキングの限界 |

### イメージ抑圧のボトルネック

**選択度がドレインタンク 1 段しかありません。**
アンテナ → J1 ソースは +0.3 dB で完全にフラット（ゲート接地の入力側に同調がない）。

実効ロード Q は **22** まで落ちており、**主因はミキサゲート容量のタンクへの反射**です。
（容量タップ化で改善しましたが、まだタンクを重く負荷しています）

**60 dB には同調回路をあと 2 段（各 20 dB 強）必要です。**
80 MHz 固定なら固定 BPF で組めますが、76–95 MHz 可変ならトラッキングが 3 連になります。

イメージ周波数は受信周波数 + 21.4 MHz（上側ヘテロダインのため）。
例：80 MHz 受信時のイメージは **101.4 MHz**。日本の FM 帯（〜95 MHz）を外れるので、
**76–73.6 MHz あたりの受信時のみ帯域内にイメージが来ます**（97.4–95.0 MHz）。
実用上の影響は限定的と考えられます。

## 9. 調整手順

### 9.1 順序は IFT が先

**理由は2つ：**

1. **IFT だけは信号なしで正解位置が分かっている。**
   L3 = 4.7 µH になるコア位置（最小から約 25 %）は実測済みなので独立に決められる。
   他の段は受信しないと合わせられない
2. **IFT を先に合わせると IF 出力が最大になり、その後の L1 調整が見やすくなる**

IFT の調整は微細かつ可逆（コアを回すだけ）なので、
L1（巻きを伸縮＝粗くて戻しにくい）を挟んだあとに再度追い込めば収束します。

### 9.2 先に警告：オシロには局発のほうが大きく見えます

**IF-OUT では局発 95 MHz の漏れ（4.69 mV）が IF（2.10 mV）より 7 dB 大きい。**
そのまま見ると **95 MHz の波形が主で、10.7 MHz はその変動として乗って見えます。**

**対策（必ずどれかを実施）：**

1. **オシロの帯域制限（20 MHz BW Limit）を ON** ← 一番簡単で確実。10.7 MHz は通り 95 MHz は大きく落ちる
2. FFT 機能があればそちらを使い、10.7 MHz のピークだけを見る
3. **プローブは必ず ×10。** ×1 は入力容量が 100 pF 近くあり、**330 Ω 負荷を潰して IFT も狂わせます**（×10 なら 15 pF 程度）

### 9.3 手順

**Phase 0（電源を入れる前）**

- [ ] L1 を予測どおり **0.6 mm 伸ばす**（L2 が +11.8 % だったので L1 も同程度と予想）
- [ ] **IFT のコアを最小から約 1/4 の位置に置く**（L3 ≒ 4.7 µH 相当）
- [ ] オシロの帯域制限を ON、プローブ ×10

**Phase 1：動作確認**

- [ ] アンテナ接続（**1〜2 m 程度のワイヤ**。電界強度が低い地域では長めに）
- [ ] 電源 ON、**強い局**にバリコンを合わせる
- [ ] IF-OUT に **10.7 MHz** が出ているか確認。**周波数も読む**
- [ ] J1 のドレインを観測し、**アンテナを外した状態で局発以外の成分が出ていないこと**を確認（寄生発振チェック）

> **Phase 1 で 10.7 MHz が見えない、あるいは想定と違う周波数が出ている場合、その値が最重要の手がかりです。**
> 73 MHz 台なら 3.2 節の寄生発振、12 MHz 台なら偽 IF を疑ってください。

**Phase 2：IFT のコアをピークに**

**Phase 3：L1 を伸縮してピークに**

**Phase 4：IFT を再ピーク**（相互作用は小さいので 1 回で収束）
→ 帯域両端（76 MHz 付近・95 MHz 付近）を確認

### 9.4 コイル巻き上げ後のチェック

L3 を 27 T 巻いたら、**コア全挿入・全抜きを測ってください**（どちらも µH レンジなので信頼できます）。

- **全挿入 6〜8 µH、全抜き 2.2〜2.9 µH** 付近なら予測どおり → そのままコアを回して 4.7 µH に合わせる
- 全挿入が 5 µH 程度しか出なければ **2〜3 T 追加**
- 9 µH 超なら **2〜3 T 減らす**

## 10. 平衡ミキサ（検討したが不採用）

LO 漏れ対策として単一平衡ミキサを検討しましたが、**初号機では採用しませんでした。**
将来の改良の参考として記録を残します。

### 10.1 対称性の取り方が本質

二乗特性デバイス `id = β(vgs − Vt)²` で展開すると：

| 構成 | 結果 |
|---|---|
| **LO 逆相・RF 同相** | **IF 積と LO 基本波が同じ対称性に乗るので、差動で取っても LO は消えない**（実測 IF/LO = −4 dB、むしろ悪化） |
| **RF 逆相・LO 同相・IF 差動取り出し** | `id1 − id2 = 4β·vrf·(V0 − vlo)` となり、**IF 積は残って LO 基本波だけが消える** ← 正解 |

### 10.2 実測（RF 20 mV@80 MHz、LO 300 mV@90.7 MHz、330 Ω 負荷）

| 構成 | IF 出力 | IF-OUT の LO 漏れ | 変換利得 | IF/LO |
|---|---|---|---|---|
| シングルエンド（rev2） | 11.7 mV | 7056 µV | −4.6 dB | +4.4 dB |
| 単一平衡・Vp 完全一致 | 15.5 mV | 0 µV | −2.2 dB | ∞ |
| 単一平衡・Vp ばらつき 3 % | 15.4 mV | 44 µV | −2.3 dB | +50.9 dB |
| 単一平衡・Vp ばらつき 10 % | 15.2 mV | 142 µV | −2.4 dB | +40.6 dB |
| 単一平衡・Vp ばらつき 20 % | 15.0 mV | 272 µV | −2.5 dB | +34.8 dB |

**Vp が 20 % ばらついても 30 dB 改善**します。

### 10.3 不採用の理由

平衡型は以下の **3 つを同時に成立させる必要**があります：

1. RF 2次の接地センタータップ
2. IFT 一次のセンタータップ
3. 2SK3557 の Vp 選別

**シミュレーションで 4 回作り直しても正しく IF が出ませんでした。**

| 回 | やったこと | 失敗理由 |
|---|---|---|
| 1 | LO 逆相・RF 同相 | 二乗特性だと IF 積と LO 基本波が同じ対称性に乗る（IF/LO −4 dB） |
| 2 | RF 逆相・LO 同相に修正 | ドレイン電源を繋ぎ忘れ（Vds ≒ 0） |
| 3 | 2次巻線 1 本（フローティング） | **ゲートに同相成分の接地経路がなく、ソースの LO が Cgs 経由でゲートに丸ごと乗る。** vgs(LO) が 120 mV → 20 mV に潰れ、元の C4 = 5p と同じ失敗 |
| 4 | バイフィラ 2 本・接地点で外部接続 | vgs(LO) は 74 mV に回復（正解方向）。だが IF 側でまだ打ち消しが残り、利得 −26 dB |

> **3 回目が特に示唆的です。2次巻線を 1 本にすると原理的に動きません。**
> 必ず「バイフィラ 2 本を接地点で繋ぐ（＝センタータップ相当）」が要ります。
> **タップは消えず、場所が移るだけでした。**

### 10.4 判断材料

- **イメージ抑圧には一切効きません。** 60 dB の話は RF 側の選択度であり、平衡化とは直交します
- **変換利得不足の解決にもなりません。** あれは rev2 のゲート低 Z 駆動で解決済みの別問題です
- **R8 = 330 Ω の先にセラミックフィルタが入るなら、LO 漏れは既に 30〜40 dB 落ちます。**
  平衡ミキサの主な御利益はフィルタと重複します。
  **独立に効くのは偶数次 IMD・AM 抑圧・強入力耐性のほう**です

### 10.5 もし将来やるなら

巻線の発想は正しく、**バイフィラで 2 本巻いて外で接続するほうが、
1 本の巻線に途中タップを出すより作りやすく対称性も良くなります。**
平衡回路で効くのは左右の対称性なので、バイフィラ巻きは理にかなっています。

追加コストは 2SK3557 が 1 個、巻線のタップが 2 箇所。
**LO 側はむしろ楽になります**（同相注入なのでバランも位相分割回路も不要）。
RF タンク（L1）にセンタータップを付けて「共振バラン」として使えば、
RF 側のバランスが崩れても変換利得が少し落ちるだけで **LO 抑圧は劣化しません**
（共通モード RF は原理的に変換されないため）。

### 11.1 再構成の検証結果（実測で決着）

再構成ネットリストの DC 動作点を JFET の自己バイアス方程式 `Id = β(|Vp| − Id·Rs)²`
（β = 25 m、|Vp| = 0.7 V）で解き、記録値および**実測値**と照合しました。

| 素子 | ソース抵抗 | 解析解 | 記録値 | 実測 | 判定 |
|---|---|---|---|---|---|
| J1 | R1 = 100 Ω | 3.34 mA | 3.3 mA | — | 一致 |
| **J2** | **R5 = 2.2 k** | **0.27 mA（Vs 0.596 V）** | ~~1.0 mA~~ | **Vs 0.624 V → 0.28 mA** | **実測が解析解と一致。記録が誤り** |
| J3 | R7 = 1 k | 0.55 mA | 0.55 mA | — | 一致 |
| J4 | R10 = 470 Ω | 1.05 mA | 1.05 mA | — | 一致 |

**J2 のソース電圧の実測 0.624 V は、解析解 0.596 V と 5 % 以内で一致しました。**
したがって **R5 = 2.2 kΩ は正しく、記録にあった「J2 1.0 mA」のほうが誤りです。**
再構成ネットリストは 4 素子すべてで検証されたことになります。

局発単体の過渡解析でも裏が取れました：

| | 再構成シミュレーション | 記録 |
|---|---|---|
| J2 の Id | 0.271 mA | ~~1.0 mA~~ |
| J2 のソース電圧 | 0.596 V | （実測 0.624 V） |
| gm | 5.20 mS | — |
| LO タンク振幅（CVLO 24p） | 742 mVpp（= 371 mV 振幅） | 398.3 mV |
| LO 周波数（CVLO 24p） | 91.66 MHz | 90.75 MHz |

**ただし起動余裕は記録の見込みより薄いです。**
gm = 5.2 mS に対して必要な gm は約 2.9 mS（タンクの並列損失 1.8 kΩ と
R5 の反射分 8.8 kΩ から算出）なので、**余裕は約 1.8 倍**。
記録の「起動余裕十分」は Id 1.0 mA（gm 10 mS）を前提にした記述でした。

シミュレーションでは安定に発振しており実害はありませんが、
**実機で発振が弱い／起動しない場合は R5 を 1 k〜470 Ω に下げるのが第一の対策**になります。

## 11.5 【重要】J2 のソース・ドレイン逆接続について

実機で **J2 のソースとドレインが逆に接続されている**ことが判明しました。

### 壊れません。動作もします

JFET は BJT や MOSFET と違い、**チャネルが構造的にほぼ対称**です。
ボディダイオードも無いので、D と S を入れ替えても破壊しません。

実際、電位の低い側が自動的にソースとして機能するため、
**DC 動作点は変わりません。** 実測 0.624 V が解析解 0.596 V と一致したのがその証拠です。

### 変わるのは Cgs と Cgd が入れ替わること

2SK3557 のモデルは **CGS = 7.1 pF / CGD = 2.9 pF** と 2.4 倍の非対称があります。
D/S を入れ替えると、この 2 つが付く端子が入れ替わります。

| | ゲート → +5V（交流接地） | ゲート → C6/C7 タップ |
|---|---|---|
| 正常（D が +5V） | Cgd 2.9 pF ＝ **タンクに加算** | Cgs 7.1 pF ＝ 帰還分圧に加算 |
| 逆接続（S が +5V） | Cgs 7.1 pF ＝ **タンクに加算** | Cgd 2.9 pF ＝ 帰還分圧に加算 |

タンク容量が実質 **+3 pF 程度**増えるので、LO 周波数が下がります。

### 実害の定量（局発単体の過渡解析）

| バリコン | 正常 | 逆接続 | ずれ |
|---|---|---|---|
| 30 pF | 86.962 MHz | 86.252 MHz | **−0.710 MHz（−0.82 %）** |
| 24 pF | 91.660 MHz | 90.825 MHz | **−0.835 MHz（−0.91 %）** |
| 15 pF | 100.408 MHz | 99.304 MHz | **−1.103 MHz（−1.10 %）** |
| 10 pF | 106.506 MHz | 105.185 MHz | **−1.321 MHz（−1.24 %）** |

タンク振幅も 742 → 711 mVpp（−4 %）と下がりますが、変換利得への影響は −0.35 dB で無視できます。

**結論：J2 だけなら実害は軽微です。** 受信周波数が約 1 MHz 下にずれ、
帯域の上端が 95.3 → 94.5 MHz と 0.8 MHz 削られる程度。
RF タンク（実効ロード Q = 22、3 dB 帯域 3.6 MHz）の中に収まるので、損失は約 1 dB です。

### J1・J3・J4 は正常でした（実機確認済み）

**逆になっていたのは J2 のみ**と実機で確認されました。以下は参考として残します。

もし **J1（RF アンプ）が逆だった場合は影響がはるかに大きくなります。**
将来 FET を交換するときの注意として記録しておきます。

J1 のドレインは RF タンクそのもの。RF タンクは LO タンクより容量が小さいので、
同じ +4.2 pF が効く割合が大きくなります。

| バリコン | RF タンク正常 | RF タンク逆接続 | ずれ |
|---|---|---|---|
| 30 pF | 76.42 MHz | 73.55 MHz | **−2.86 MHz（−3.7 %）** |
| 24 pF | 80.89 MHz | 77.51 MHz | **−3.37 MHz（−4.2 %）** |
| 15 pF | 89.51 MHz | 85.00 MHz | **−4.51 MHz（−5.0 %）** |
| 10 pF | 95.78 MHz | 90.31 MHz | **−5.47 MHz（−5.7 %）** |

**J1 と J2 の両方が逆だと、ずれ方が違うのでトラッキングが崩れます。**

| バリコン | 受信周波数 | RF タンクのピーク | 離調 |
|---|---|---|---|
| 30 pF | 75.55 MHz | 73.55 MHz | **−2.00 MHz** |
| 24 pF | 80.12 MHz | 77.51 MHz | **−2.61 MHz** |
| 15 pF | 88.60 MHz | 85.00 MHz | **−3.60 MHz** |
| 10 pF | 94.48 MHz | 90.31 MHz | **−4.18 MHz** |

RF タンクの片側 3 dB 帯域は 1.8 MHz なので、**全域で帯域外**。
帯域上端では 4 MHz 離調＝**−7 dB 程度**の損失になります。

L1 を縮めて RF タンクを上げれば中央では合わせられますが、
**ずれ方が周波数依存なので、片側を合わせると反対側が悪化します。**

### 対処：2通りとも有効（実機は J2 のみ逆接続）

#### 案A：J2 を付け替える（推奨）

SOT-23 のピン配置は **ピン1 = ソース／ピン2 = ドレイン／ピン3 = ゲート**（onsemi データシート）。
ゲートが単独側、ソースとドレインが同じ側の 2 本です。作業は数分。
ネットリスト・定数表と実機が一致するので、将来の混乱がなくなります。

#### 案B：C5 を 11 pF → **10 pF** に変更して逆接続のまま使う

**この補正は帯域全域で成立します。** 逆接続によるタンク容量の増加は
バリコン位置に依存しない固定分なので、固定容量 1 pF を減らすだけで全域が戻ります。

| バリコン | 正常（C5 = 11 p） | 逆接続＋C5 = 10 p | 残差 |
|---|---|---|---|
| 30 pF | 86.962 MHz | 86.966 MHz | **+4 kHz** |
| 24 pF | 91.660 MHz | 91.661 MHz | **+1 kHz** |
| 15 pF | 100.408 MHz | 100.401 MHz | **−6 kHz** |
| 10 pF | 106.506 MHz | 106.492 MHz | **−14 kHz** |

タップ振幅（LO バッファの入力）は 410 → 384 mVpp（−6 %）とわずかに下がりますが、
変換利得への影響は −0.6 dB 程度で実用上は問題ありません。

> **補正量が 1 pF である理由**（手計算では 3 pF と誤りました）
>
> SPICE の JFET 接合容量は逆バイアス依存で `C = C0/√(1+V/PB)` です。
> ゼロバイアス値（CGS 7.1 p / CGD 2.9 p）をそのまま使うと 3 倍間違えます。
>
> | | ゲート→交流接地（Vr = 5 V） | ゲート→タップ（Vr = 0.6 V） |
> |---|---|---|
> | 正常 | Cgd 2.9/√6 = **1.18 p** | Cgs 7.1/√1.6 = **5.62 p** |
> | 逆接続 | Cgs 7.1/√6 = **2.90 p** | Cgd 2.9/√1.6 = **2.30 p** |
>
> タンクへの直接加算 +1.72 p、帰還分圧の直列合成が 14.77 → 14.05 p で **−0.72 p**。
> 差し引き **+1.00 pF** ── シミュレーション結果と一致します。

### テスタでの判別について

**JFET の D と S はテスタでは判別できません。** これは覚えておく価値があります。

- ゲートはチャネルに対してダイオードを形成するので、**ゲートだけは判別できます**
  （N チャネルなので、ゲートを ＋ にしたとき他の 2 本の両方に導通）
- **D と S は構造的に対称なので、ダイオードチェックでは区別がつきません**

したがって **データシートのピン配置とパッケージの向きに頼るしかありません。**
IF ストリップの SOT-23 と同じく、実装前に機械的な検算をしてください。

```
すべての FET について  sign( (S→D) × (S→G) )  を計算し、
全個体で符号が一致することを確認する
```

**在庫の単体で確認する方法**：ブレッドボードでソース接地アンプを組み、
「ソースと思ったほう」を GND、「ドレインと思ったほう」を抵抗経由で +5V に繋いで
ドレイン電圧を見る。向きが正しければ数 V、逆でも動きますが、
**ゲート容量を LC メータで測れば区別できます**（G–S が約 7 pF、G–D が約 3 pF）。

### 11.2 ngspice での確認について

再構成ネットリストは ngspice でも動作しますが、**`.op` が高インピーダンスのゲートノードで
残差を残します**（本来 0 V であるべき J1・J4 のゲートが数百 mV を示す）。
発振回路を含む回路の DC 解は数値的に不安定なので、
**動作点の確認は上表の解析解で行うのが確実です。**

過渡解析を行う場合は `.tran 0 40u 0 200p` とし、FFT は定常部（24–40 µs）のみを選択してください。

**シミュレーション設定の注意**

| 項目 | 元 | rev3 | 理由 |
|---|---|---|---|
| `.tran` | `0 2u 0 1n` | **`0 40u 0 200p`** | 2 µs では局発が立ち上がり途中で、**寄生発振も見えない**。maxstep 1 n（1 GS/s）は 100 MHz 超の FFT に粗い |
| FFT 範囲 | 全区間 | **定常部（24–40 µs）のみ** | 過渡込みだとスペクトルが滲む |

## 12. IF ストリップとの接続

| 項目 | 仕様 |
|---|---|
| フロントエンド出力 | IF-OUT（R8 330 Ω） |
| 接続 | IF-OUT → **セラミックフィルタ SFELF10M7GA00** → 330 Ω 終端 → C1(100p) → リミッタ1段目 IN A |
| フィルタ GND ピン | **1段目の基準点へ最短で** |
| 1段目 IN B | 交流接地 |

**フィルタの OUT ピン → 330 Ω → C1 の区間は 1〜2 ピッチ以内に詰めること。**
フィルタより後ろで拾ったノイズは濾過されません。

### 周波数安定度の要求

IF ストリップの検波直線範囲は **±75 kHz**（`HANDBOOK.md` 第3章）。
局発 86.7–105.7 MHz に対して 30 kHz は **0.03 %** です。

**手の容量でこれを超えるのであれば、シールドケースは感度対策ではなく安定度対策として必須です。**
バリコンのロータを Cb 経由で実 GND に落としてあるのはその対策の一部ですが、
コイル（空芯 3〜4 T）とバリコン本体は依然として手の容量を拾います。

> AFC は不採用としていますが、ドリフトが実用上の問題になる場合は
> 検波出力（AFE の DC 成分）を LO のバリキャップに戻す形で再検討の余地があります。
> ただし本 IF 部の出力は **周波数上昇で電圧上昇**（OB から取り出しているため）なので、
> **AFC ループの極性に注意**が必要です。
