## 1. 一言でいうと

V3 は「パイロットを高 Q の BPF で取り出して PLL に入れる」方式で、**BPF の位相がオペアンプの GB 積と部品誤差でずれ、
38 kHz のスイッチングタイミングが約 74° 遅れていました**。補正して 31〜37 dB まで上げましたが、再現性がありません。

V4 では専用 IC と同じく、**VCO から作った 19 kHz でコンポジットを直接掛け算して PLL をロックさせます**。
BPF が無くなり、ロック位相が分周器の論理で決まるので、**部品定数にほとんど左右されません**（シミュレーションで 38 kHz 誤差 0.4°）。

```

・電源 5 V 単一
・IF 10.7 MHz、日本ワイド FM 76〜95 MHz
・入力は IF 基板の MPX OUT：Q16 エミッタフォロア1段、100 % 変調で約 0.8 Vpp、VR 50k で可変
  （HANDBOOK 11.3 の Q17/Q18 利得段は実装していない。フロントエンド〜検波基板は V4 でも変更しない）
・検波後 LPF（220 pF）はセパレーションのボトルネックではない（RV2 補正後 約 58 dB @15 kHz。旧記述の 35.2 dB は補正なしの最悪値）
・SMD（1608 / SOT-23 / TSSOP / SOIC）で可。キット化するなら DIP 変換も考慮
・部品配置・基板レイアウトはユーザーが決める（AI は回路と定数まで）
・トランジスタは 2N3904 が大量にある。汎用品は多数手持ち
・検証：ngspice（AI 側）、Analog Discovery 3 ＋ オシロ（ユーザー側）
```

## 3. 現行 V3 基板の状態

### 3.1 構成（V3）

```
J1 → U2C バッファ（2.5 V）─┬→ U1A（38k=H で ON）→ SIG-L → 4次 SK-LPF（U6）─┐
                          └→ U1D（38k=L で ON）→ SIG-R → 4次 SK-LPF（U6）─┴→ U7 マトリクス（RV2）→ デエンファシス → OUT-L/R
J1 → Q1 → U2A/U2B MFB BPF（Q≈9×2）→ LM393 U4A → 19KHzRect → 74HC4046 PC2 ← U5A（19 kHz）← U5B（38 kHz）← VCO 76 kHz
19KHzSin → Q2 → D1 → PILOT-V → U4B（vs 2.5 V）→ VCO_ENABLE（ゲート駆動・LED・VCO 停止）
```

### 3.2 実機とネットリストの差分

| 部品 | ネットリスト | 実機 |
|---|---|---|
| R24 | 10k | **1k** |
| R33 / R35 | 10k | 10k ∥ **220 pF** |
| R21 / R27 | 47 Ω | 47 ∥ **1.5 k**（実測 45.5 Ω） |
| RV2 | 5k 半固定 | **2.2 k 固定**（半固定は調整中に破損） |

### 3.3 V3 の実測性能（AD3 の規格信号、コンポジット振幅 200 mV）

| 項目 | 値 |
|---|---|
| L→R / R→L | **37.1 dB / 31.4 dB** |
| 主出力 | −22.9 dBV |
| 漏れの位相 | 主信号に対し 163〜165°（RV2 がわずかに大きい → 2.08 kΩ で約 40 dB の見込み） |
| 入力範囲 | ステレオ判定に約 0.4 Vpp 以上、Q1 の位相が安定するのは約 0.5 Vpp 以下（**窓が狭い**） |

### 3.4 IF〜検波基板の実機（2026-09-26、LTspice の配線図 `netlist/IFAMP_asbuilt_ltspice.net` で確認）

V4 に関係する点：**検波後 LPF は C20・C21・C23 すべて 220 pF で実装済み、出力は Q16 エミッタフォロア1段（R53 4.7k、C22 10 µ、VR R52 50k）**。
Q17/Q18 の利得段は無い。→ MPX OUT は 100 % 変調で約 0.8 Vpp（検波感度 5.375 mV/kHz × 150 kHz）。

ドキュメント（HANDBOOK・`ifsys_final.net`）と配線図の相違（V4 には影響なし、記録のみ）：

| 項目 | ドキュメント | 配線図 |
|---|---|---|
| ピーキングコイル 6.8 µH（1・2段目） | あり | **未接続（実機確認済み）** |
| リミッタの電源 | 共通 RS 10 Ω ＋ 段別 22 Ω | 段別 22 Ω ＋ 10 µ ＋ 0.1 µ のみ（過去の「差動対 1段 実験回路 rev.E」の図に基づく。実機が正）。**VK 実測 4.80 V（4段とも）**＝計算 4.81 V と一致 |
| 1段目の未使用入力の結合 C（CIB） | 100 p | 1000 p（C3、同上の図の CG2＝交流接地。実機が正） |
| 2SK3557 モデル | VTO −0.771 / BETA 25.2m（実測フィット） | −0.7 / 25m（配線図用なので影響なし） |

### 3.5 マトリクスの式（V4 でもそのまま使う）

```
r = RV2 / 10k（0〜0.5）
OUT_L = −[(1−r)·SIG_L − r·SIG_R]、OUT_R = −[(1−r)·SIG_R − r·SIG_L]
漏れ ∝ 1 − k − 2r      k：スイッチの復調効率（理想 (2/π)·cosθ）
最適 r = (1 − k)/2     同相の漏れ＝RV2 小さすぎ、逆相の漏れ＝RV2 大きすぎ
```

V3 の実測フィットでは k = 0.564、最適 RV2 = 2.18 kΩ。**V4 では θ が変わるので k も変わり、RV2 の最適値は取り直しになる。**
RV2 は「固定抵抗＋小さい半固定」（例：1.8k ＋ 500 Ω）にすること。5 k 単回転では ±100 Ω（回転角 ±2 %）に合わせられない。

## 4. V4 で決まっていること

| # | 決定事項 | 根拠 |
|---|---|---|
| D1 | **音声経路は V3 のまま**（U2C → U1A/U1D → U6 → U7 → デエンファシス、ゲート駆動 Q3〜Q6、LED、VREF の U2D） | 問題はパイロット経路だけだった |
| D2 | **U5A/U5B の分周（76k → 38k → 19k）はそのまま** | 逓倍の仕組みは V3 と同じ（VCO÷4 をパイロットと比較） |
| D3 | **74HC4046 は VCO としてだけ使う**（PC2 とそのループフィルタは撤去） | 既に基板にあり、5 V フル振幅の矩形が出る。組み立てやすさ・再現性を優先 |
| D4 | **位相比較＝±1 乗算器**（U8A スイッチ ＋ U2A）でコンポジット × Q | 全波なのでバイアス誤差・音声が DC に出ない |
| D5 | **Q＝I を 90° 遅らせた 19 kHz**（U9A：D=I、CK=/38k） | 掛け算型は直交でロックする。論理で決まる 90° なので誤差なし |
| D6 | **ループフィルタ＝PI 積分**（U2B） | 周波数ずれが定常位相誤差にならない（type 2） |
| D7 | **ステレオ検出＝切替 RC ペア**（U8B：I、U8C：/I）→ U4B | 同期検波。バイアス誤差がコモンモードで消える |
| D8 | **VCO は常時動作**（INH を GND、U1C・R8 の VCO 停止は撤去） | VCO の I でパイロットを検出するため。止めると二度とステレオにならない |
| D9 | **COMP（U2C 出力）で 2 Vpp（100 % 変調）にする。U2C を 2.5 倍の非反転増幅に変更**（R 15k を出力→−入力、R 10k を−入力→VREF。仮番号 R71/R72） | 位相比較の感度とステレオ判定の余裕が入力に比例。IF 基板の出力は約 0.8 Vpp。利得を検波基板のトランジスタ段で取ると 5 V で飽和しやすい。NJM2747 は**出力のみレール・ツー・レール**（0.1〜4.9 V）で、**入力同相範囲は 0〜4 V**（−40〜125 °C で 0〜3.5 V）。COMP は 1.5〜3.5 V（120 % 変調で 1.3〜3.7 V）なので範囲内。GB 積 10 MHz / 2.5 = 4 MHz で 53 kHz は平坦 |
| D11 | **フロントエンド〜検波基板は変更しない** | 検波後 LPF 220 pF は実装済みで、V4 のボトルネックにならない。出力レベル不足は D9 で解決 |
| D10 | **撤去**：Q1・R6・R9・R10・C2・C9、BPF（R20・R21・R25〜R27・R29・C11〜C15）、C16・R32・U4A・R37、Q2・C1・R3・R7・R11・D1・R14・R15・C6・R18・R19、R16・R17・C8、R8 | |

### 4.1 VCO についての結論（議論の記録）

- 4046 を VCO だけで使っても回路全体は PLL のまま（位相比較 → ループフィルタ → VCO → 分周 → Q の帰還ループ）
- 555（CMOS 版推奨）、トランジスタのマルチバイブレータ、オペアンプ（積分器＋コンパレータ）でも組める
- **VCO への要求は緩い**：デューティ不問（U5B が立ち上がりだけでトグル）、Kv の直線性ほぼ不問、Kv の符号も不問（逆なら I がパイロットと同相でロックし、38 kHz は同じ。SA/SB が入れ替わるだけ）
- **ジッタの要求も緩い**：38 kHz で σ=5°（0.37 µs rms）でも復調効率の低下は 0.4 %（RV2 で吸収）。普通に組んだ発振器の ns 級ジッタは問題にならない
- ディスクリート VCO の実際の課題は **自走周波数の温度ドリフト（±3 % の引き込み範囲に収める）、電源リップル感度、74HC 向けのエッジ整形**
- 方針：**まず 4046 で V4 を成立させ、学習用に後でディスクリート VCO（2N3904 のエミッタ結合マルチバイブレータなど）に差し替える**。接続は「VCTL 入力 → 76 kHz 矩形出力」だけなので、**基板上で VCO を独立ブロックにしておく**

### 5.2 設計式

```
パイロット振幅    Vp = 0.1036 × コンポジット振幅（規格信号の場合）
位相比較の感度    Kd = (2/π)·Vp  [V/rad]
VCO 利得         Kv19 = Kv76 / 4  [rad/s/V]（19 kHz 換算）
自然周波数       ωn = √( Kd·Kv19 / (R63·C40) )
減衰係数         ζ  = ωn·R64·C40 / 2
ステレオ検出     SB−SA = (4/π)·Vp（ロック時）
```

仮定 Kv76 = 30 kHz/V のとき：

| 入力 | Vp | Kd | ωn | ζ |
|---|---|---|---|---|
| 1 Vpp | 51.8 mV | 33 mV/rad | 29 Hz | 0.68 |
| 2 Vpp | 104 mV | 66 mV/rad | 41 Hz | 0.97 |

## 6. シミュレーション

### 6.1 ファイルとモデル

| ファイル | 内容 |
|---|---|
| `netlist/sync_pll.tmpl` | 過渡解析のテンプレート（`{AMP}` などを置換） |
| `scripts/sync_run.py` | 置換 → ngspice 実行 → 結果の読み込み（1 ケース約 30 秒） |

モデルの前提：

- スイッチ：ngspice の `SW`（Ron 150 Ω）
- オペアンプ：単極（A0 = 1e5、GB 積 10 MHz）、**スルーレートを明示（SR 3 V/µs）**、出力 0.05〜4.95 V
- VCO と分周器：動作モデル。位相を**パイロットに対する相対値**として積分（`V(ph)`）、I・Q・38k は tanh で作る矩形
- コンポジット：規格式（L のみ 1 kHz 100 %、パイロット 10 %）
- 結果の読み方：`psi` ＝ I とパイロットの位相差、38 kHz の誤差＝ angle(exp(2j·psi))（0° でも 180° でも正常）

> **モデルの落とし穴（実際に踏んだもの）**
> 1. オペアンプ内部を ±5 V で制限すると、スルーレートが実質 0.003 V/µs になり位相比較器に 25° の偽の誤差が出る。**SR は明示すること**
> 2. VCO の位相を絶対値（2π·19000·t）で積分すると、reltol で数 rad の誤差になる。**パイロットとの差として積分すること**
> 3. `.ic` が効かない場合がある。**コンデンサの `IC=` で初期値を与える**
> 4. 新しいモデルを使う前に、**ループを切って位相比較器だけを動かし、理論式 −(2/π)·Vp·sinψ と照合する**

### 6.2 結果（入力 1 Vpp、L のみ 1 kHz 100 %）

| ケース | 38 kHz 誤差 | 備考 |
|---|---|---|
| 基準 | **0.4°** | V3 は約 74°。ジッタ 0.6° pp |

| O5 | 入力レベル 2 Vpp での音声経路の余裕 | 主出力は V3 測定時（0.4 Vpp）より約 14 dB 大きくなる（−22.9 → 約 −9 dBV） | U6・U7 の振幅をシミュレーションで確認 |

| O6 | オペアンプ | NJM2747 のままで可（BPF が無いので GB 積は不問）。データシート：GB 10 MHz、SR 3.5 V/µs、**Vos typ 1 mV / max 6 mV**（25 °C、全温度 max 12 mV）。シミュレーションの Vos 3 mV は typ の 3 倍だが max の半分。最悪値では 38 kHz 誤差が 2 Vpp でも 20〜30° になりうる（固定分は RV2 で吸収、cos30° = 0.87） | 実機の VCTL を見て Vos の影響を確認。気になるなら低 Vos 品、または U2A の Vos を打ち消す構成を検討 |
| O10 | 入力同相範囲 | NJM2747 の入力は 0〜4 V（全温度 0〜3.5 V）。U2A の＋入力には COMP（最大 3.7 V @120 %）がそのまま入る | 常温では問題なし。入力を上げすぎないこと（COMP 2 Vpp を上限の目安に） |
| O7 | 57 kHz の副搬送波 | 矩形の 3 倍高調波で感度がある | 実放送で確認 |
| O8 | ディスクリート VCO | 学習用の将来課題（4.1 節） | V4 が動いてから |

## 10. AI と進めるときの注意（このプロジェクトでの実績から）

- **回路図（ネットリスト）を最初に渡す**。渡す前の AI の推論は仮説。V3 では渡した時点で AI の回路モデルが 2 回書き換わった
- **部品番号はネットリストの番号で**。AI は教科書の記号（R3 など）で呼びがち
- **測定を指示させる前に**：エイリアシング、ダイナミックレンジ、被測定回路の入力範囲、調整箇所の現在位置の記録、の 4 点を確認させる
- **シミュレーションモデルは開ループで理論式と照合してから使う**（6.1 節の落とし穴）
- **仮説は試験信号で検証する**。V3 ではパイロット位相を ±37° ずらした信号で、回路を触らずに原因と向きを確定できた
- **予測を先に出させる**。1.5k 並列後の予測（約 30 dB）は外れた（実測 14 dB、RV2 の再調整が必要だった）。外れたら理由を追う
