## 0. この資料の読み方（信頼度の区別）

数値には必ず次のどれかの印を付けています。**【実測】以外は設計の目安で、実機で確かめる前提です。**

| 印 | 意味 | 信頼度 |
|---|---|---|
| **【実測】** | LC メータ・オシロ等で実際に測った値 | 高い（ただし 2 章の測定条件つき） |
| **【導出】** | 実測値から計算で求めた値 | 実測値の誤差＋計算の前提に依存 |
| **【モデル】** | 理論式・仮定で求めた値 | 目安。実測で校正が必要 |
| **【未測定】** | 今回データがない項目 | 7 章の手順で測定を推奨 |

## 2. 測定条件と前提（すべての数値に共通）

1. **測定器は LC メータ**（機種・測定周波数は記録なし）。**使用周波数（10.7 MHz）で測った値ではない。**
   フェライトの透磁率は周波数で変わるため、10.7 MHz での実効 L はメータ値と数 % 違う可能性があります。
2. **LC メータの読みは 100 nH 以下では信用できません。**【実測】

   | 巻数（コアなし） | メータ読み | 理論値（Wheeler） | 読み／理論 |
   |---|---|---|---|
   | 3 T | 22 nH | 81〜87 nH | 0.25 |
   | 6 T | 100 nH | 267 nH | 0.37 |
   | 20 T | 1450 nH | 1633 nH | **0.888** |

   コア入りの読み（参考）：3 T 50 nH（コア比 2.27 倍）、6 T 300 nH（3.0 倍）、20 T 4.00 µH（2.76 倍）。
   3 T・6 T は絶対値が信用できないが、倍率誤差は比で相殺されるので比は参考になる。
   コア入りのスケール指数は 3→6 T で N^2.58、6→20 T で N^2.15。**巻幅がコアを覆う割合が増えると N² に近づく**（短いコイルほどコアの効きが悪い）。

   µH 帯の読みは使えます。20 T で残る 11 % の差が「メータの誤差」なのか「理論式の誤差（密巻きの仮定・線の被覆・リード分）」なのかは切り分けていません。
   **この資料のモデル値はすべて「LC メータ基準」**（Wheeler 値 × 0.888）で表しています。実機の同調は LC メータで合わせているので、この基準のほうが実用的です。
3. **理論式は Wheeler の単層ソレノイド式**（L[µH] = r²N² / (9r + 10ℓ)、r・ℓ はインチ）。
   ℓ/D が 0.4 以上（約 10 T 以上）で誤差 1 % 程度です。それ以下の短いコイルでは誤差が増えます。
4. **コア「全挿入」「全抜き」の定義**
   - 全挿入：コアの中心が巻線の中心とほぼ一致する、L が最大になる位置（と想定）
   - 全抜き：コアをボビンから外した状態（空芯と同等）
5. **温度・個体差は未評価**です。コア 1 個・ボビン 1 個の測定から作っています。
6. 浮遊容量はクワッド検波の実測から「ほぼ効いていない」と判断しています（2.21 µH と 100 p の計算値 10.70 MHz が実測同調点と一致）。基板が変わるとこの前提は崩れます。

## 3. 基本特性

### 3.1 コアなし（空芯）【モデル（20 T の実測で校正）】

| 巻数 | 巻幅（mm） | L（µH、LC メータ基準） | AL（nH/T²） |
|---|---|---|---|
| 10 T | 2.10 | 0.53 | 5.3 |
| 12 T | 2.52 | 0.70 | 4.9 |
| 15 T | 3.15 | 0.97 | 4.3 |
| 17 T | 3.57 | 1.16 | 4.0 |
| 18 T | 3.78 | 1.26 | 3.9 |
| **20 T** | **4.20** | **1.45【実測】** | **3.6** |
| 22 T | 4.62 | 1.65 | 3.4 |
| 24 T | 5.04 | 1.85 | 3.2 |
| 27 T | 5.67 | 2.16 | 3.0 |
| 30 T | 6.30 | 2.47 | 2.7 |
| 35 T | 7.35 | 3.00 | 2.4 |

> 空芯の AL は一定ではありません（巻幅が伸びると下がる）。**「L ∝ N²」は空芯では成り立ちません。**

### 3.2 コア全挿入【実測 1 点 ＋ モデル】

**実測（20 T）：全挿入 4.00 µH ／ 全抜き 1.45 µH → コア効果 2.76 倍、全挿入時の AL = 10.0 nH/T²**

20 T 以外は 2 つのモデルで挟んでいます。**真値はこの範囲内にあると想定**しています（20 T から離れるほど幅が広がる）。

| 巻数 | モデル A：AL 一定（10.0 nH/T² × N²） | モデル B：比一定（空芯 × 2.76） | 推定範囲（µH） |
|---|---|---|---|
| 10 T | 1.00 | 1.47 | 1.0〜1.5 |
| 12 T | 1.44 | 1.94 | 1.4〜1.9 |
| 15 T | 2.25 | 2.68 | 2.3〜2.7 |
| 17 T | 2.89 | 3.20 | 2.9〜3.2 |
| 18 T | 3.24 | 3.46 | 3.2〜3.5 |
| **20 T** | **4.00** | **4.00** | **4.00【実測】** |
| 22 T | 4.84 | 4.55 | 4.6〜4.8 |
| 24 T | 5.76 | 5.11 | 5.1〜5.8 |
| 27 T | 7.29 | 5.96 | 6.0〜7.3 |
| 30 T | 9.00 | 6.82 | 6.8〜9.0 |
| 35 T | 12.3 | 8.27 | 8.3〜12 |

**モデルの前提**
- A は「巻幅が変わってもコアの効き方が同じ」、B は「コアによる倍率が同じ」という仮定です。
- 巻幅がコア長 8 mm（約 38 T）を超えるとコアに覆われない部分が出るので、どちらのモデルも使えません。
- **巻数を決めるときは、推定範囲の両端の両方で、狙いの L が「全抜き〜全挿入」の中に余裕をもって入ることを確認してください。**

### 3.3 コア位置と L【実測（実機の調整点）】

**27 T（L3）＋ 9 T（L4）を巻いた実機の、コア可動域 3 点での実測**（測定誤差ありの「おおよその傾向」）

| コア位置 | L3（27 T） | L4（9 T） | L4/L3 | 実効巻数比 √(L3/L4) | L3+L4 |
|---|---|---|---|---|---|
| 最大 | 6.2 µH | 1.2 µH | 0.194 | 2.27 | 7.4 µH |
| 中間 | 5.8 µH | 0.9 µH | 0.155 | 2.54 | 6.7 µH |
| 最小 | 3.6 µH | 0.4 µH | 0.111 | **3.00**（= 27/9） | 4.0 µH |

- 「最小」はコアが可動域の端にある状態で、**ボビンから外した空芯ではない**（27 T 空芯のモデル値は 2.16 µH）。
- 「最大」6.2 µH は 3.2 節の予測 6.0〜7.3 µH の下端に入った（予測の 8 % 以内）。
- **コアを入れると L4 のほうが速く増える**（最小→最大で L4 は 3.0 倍、L3 は 1.72 倍）。
  L4 は巻幅 1.9 mm でコア長の 24 % しか覆っておらず、コアなしでは磁路が貧弱なためにコアの効きが大きい。L3 は 5.7 mm（71 %）を覆っている。
  **巻数比どおり (9/27)² = 0.111 になるのはコア最小のときだけ**で、二次の L を巻数比で決めると、コアを入れたときに設計より大きくなる。

**調整点（実機）**

| コイル | 巻数 | 調整後の L | コア位置の記録 | 位置【導出】 |
|---|---|---|---|---|
| FE T2（L3） | 27 T | 4.7 µH | 「最小から約 25 %」 | L の比率では最小〜最大の **42 %**（最小〜中間のちょうど 50 %）。「中間」が機械的な中央なら、機械的な位置は可動域の約 25 % |
| クワッド T1（LP） | 18 T | 2.21 µH | **コア上端がボビンから 2 mm 突出**（＝挿入が浅い側） | 全抜き 1.26〜全挿入 3.2〜3.5 µH の **約 45 %**（モデル基準） |

- 調整点の L4 は、最小と中間の補間で **0.65 µH**（設計 0.52 µH）。√(L4/L3) = 0.372（設計 0.333、+12 %）。
- 調整点から上に 1.5 µH、下に 1.1 µH の余裕がある。
- 「L 可変範囲の中での位置」は**インダクタンスの比率**で、**コアの機械的な移動量（mm・回転数）とは比例しない**。
- **L とコア位置（回転数）の関係を表す細かいカーブは未測定**。今後の設計で一番役に立つデータなので、7.1 の手順で 1 本取っておくことをおすすめします。

**次回の巻数の目安**：18 T でコアが 2 mm 突出したので、同じ 2.21 µH なら **17 T** でコアが約 1 段深くなり、突出が解消する見込みです（同じコア位置なら 2.21 × (17/18)² = 1.97 µH）。

### 3.4 二次巻線と結合【実測：直列（和動・差動）法】

**測定方法**：L3 と L4 を直列につなぎ、LC メータで 2 回測る（コアは L3 = 4.7 µH の調整点のまま）。

1. 加極性（磁束が強め合う向き）で直列 → **La = 7.93 µH【実測】**
2. どちらか一方の巻線の両端を入れ替えて減極性 → **Lo = 2.93 µH【実測】**
3. M = (La − Lo) / 4、k = M / √(L3·L4)

どちらも µH 帯なので LC メータで信頼して読めます。向きを間違えても La > Lo なので大きいほうが加極性です。

| 項目 | 値 | 区分 |
|---|---|---|
| 相互インダクタンス M | **1.250 µH** | 【導出】(7.93 − 2.93)/4 |
| L3 + L4 | 5.43 µH | 【導出】La − 2M。検算：5.43 − 2.50 = 2.93 = Lo |
| 測定時のコア位置 | L3+L4 = 5.43 µH は 3.3 表の最小 4.0〜中間 6.7 の 53 % → **調整点（約 25 %）とほぼ同じ** | 【導出】 |
| 結合係数 k | **0.715**（L3 4.70 / L4 0.65 を使用） | 【導出】 |
| k の幅 | **0.68〜0.72** | 【導出】L3 = 4.70 とすると L3+L4 = 5.43 から L4 = 0.73 µH となり k = 0.675。補間値どうしの和 4.70 + 0.65 = 5.35 µH と直列法の 5.43 µH の差は約 1.5 % で、測定誤差の範囲 |
| AL（L4、調整点） | 8.0 nH/T² | 【導出】線中心の直径 5.63 mm |

**測定前に出していた期待値**（L3 4.7 / L4 0.65 µH として）

| k | 加極性 La | 減極性 Lo |
|---|---|---|
| 0.90 | 8.50 µH | 2.20 µH |
| 0.75 | 7.97 µH | 2.73 µH |
| 0.60 | 7.45 µH | 3.25 µH |
| 0.45 | 6.92 µH | 3.78 µH |

判断基準：k < 0.6 なら L4 を L3 の冷側にもっと密着させて巻き直す。0.75 以上なら何もしない。0.6〜0.75 は回路側で影響を確認する。

**回路への影響（FE IFT、AC 解析【モデル】）**

解析 1：k を測る前に、L4 = 0.65 µH の影響と k の感度を見たもの

| 条件 | 共振 | Zt | −3 dB 帯域 | 90.7 MHz 減衰 | 出力（設計比） |
|---|---|---|---|---|---|
| 設計 L4 0.52 / k 0.90 | 10.74 MHz | 992 Ω | 926 kHz | 38.9 dB | — |
| 実機 L4 0.65 / k 0.90（仮） | 10.74 MHz | 906 Ω | 1173 kHz | 37.2 dB | −0.79 dB |
| 実機 L4 0.65 / k 0.75 | 10.74 MHz | 1050 Ω | 866 kHz | 40.8 dB | +0.50 dB |
| 実機 L4 0.65 / k 0.60 | 10.74 MHz | 1235 Ω | 555 kHz | 45.1 dB | +1.91 dB |
| （参考）L4 を 8 T に、k 0.9 | 10.74 MHz | 999 Ω | 926 kHz | 39.1 dB | +0.07 dB |

解析 2：実測 k = 0.71 を入れたもの

| 条件 | 共振 | Zp | Zt | −3 dB 帯域 | 90.7 MHz 減衰 | 出力（設計比） |
|---|---|---|---|---|---|---|
| 設計 L4 0.52 / k 0.90 | 10.73 MHz | 3318 Ω | 992 Ω | 989 kHz | 38.9 dB | — |
| **実機 L4 0.65 / k 0.71** | **10.73 MHz** | **4161 Ω** | **1096 Ω** | **791 kHz** | **41.9 dB** | **+0.86 dB** |

> 設計行の帯域が解析 1 と 2 で 926 / 989 kHz と違うのは、帯域の読み取り条件（周波数刻みなど）の違いと思われます（ログに記載なし）。比較は同じ表の中だけで行ってください。

- k が下がると二次側の負荷が一次に反射しにくくなり、Zp が上がる（Zp ∝ 1/k²）。Zt = Zp·k·√(L4/L3) なので正味 Zt ∝ 1/k で、**k が低いほど出力は上がり、帯域は狭くなる**。
- 791 kHz はセラミックフィルタ（約 280 kHz）より十分広く、選択度はフィルタが決める。局発（90.7 MHz）の減衰は 3 dB 改善。
- **結論：巻き直し・定数変更は不要。** ngspice/LTspice モデルは `L4 … 650n`、`K1 L3 L4 0.71` に合わせてある（`fe_rev3_ngspice.cir`）。
- 9 T を L3 の冷側に重ね巻きした構造で k = 0.6〜0.8 は典型的な値。0.9 以上が必要ならバイファイラ巻きを検討する。
- 冷側に重ねる理由：磁路を共有して k を稼ぐことと、ホット側（局発が乗るドレイン側）から離して一次-二次間の容量結合による局発漏れを減らすこと。

### 3.5 損失（Q）

| 項目 | 値 | 区分 |
|---|---|---|
| クワッド T1 の無負荷 Q（10.7 MHz、18 T） | **約 50〜80（推定）** | 【導出】SF 出力の実測 317 mVpp（期待 366 mVpp）と、駆動振幅の誤差 ±10 % から逆算した幅。直接測定ではない |
| シミュレーションで仮定した値 | LP：Rser 1.86 Ω（Q ≈ 80）／ L3：Rser 3 Ω（Q ≈ 105） | 【モデル】仮定値で、実測ではない |
| 80〜108 MHz での Q | 大きく低下すると予想 | 10.7 MHz 用フェライトのため。VHF の同調コイルには使わない（FRONTEND.md 5.1） |

### 3.6 自己共振（SRF）【モデル・未測定】

- 巻線の自己容量（Medhurst の式、ℓ/D ≈ 0.7）：**約 0.25 pF**
- ピン・リード・基板の浮遊容量：**1〜2 pF と仮定**（未測定）
- SRF の目安：2.21 µH で約 70〜95 MHz、4.7 µH で約 50〜65 MHz

10.7 MHz の同調用途には十分な余裕があります。**VHF 帯の RFC に使う場合は SRF 付近になるので、必ず実測してください**（4.2 参照）。

## 4. 設計への使い方

### 4.1 10.7 MHz 同調コイル（IFT）の設計手順

1. 必要な L を求める：L = 1 / ((2πf)² × C)。10.7 MHz・100 p なら 2.21 µH、47 p なら 4.7 µH。
2. **狙いの L が「全抜き〜全挿入」の中央付近（L の比率で 40〜60 %）に来る巻数を 3.1・3.2 の表から選ぶ。**
   C の誤差 ±5 % と浮遊容量の分を吸収するため、上下に ±20 % 程度の余裕を残してください（FRONTEND.md 5.4 の考え方）。

   | 狙いの L | 推奨巻数 | 理由 |
   |---|---|---|
   | 1.5 µH | 14〜15 T | 全抜き 0.88〜0.97 ／ 全挿入 2.0〜2.7 |
   | 2.2 µH | **17 T** | 18 T だとコアが浅すぎた（実績） |
   | 3.3 µH | 21〜22 T | |
   | 4.7 µH | **26〜27 T** | 実績（27 T 推奨値） |
   | 6.8 µH | 32〜34 T | 巻幅 6.7〜7.1 mm。コア長ぎりぎりで、モデル間の差も大きい |

3. 巻いたら、**全抜きと全挿入の両方を LC メータで測る**。予測範囲から外れていたら巻数を ±2〜3 T 直す。
4. 同調容量をつないだ状態で、実際の信号（AWG）でピークに合わせる。
5. **調整後はコアをロウかワニスで固定する。** 中心周波数を ±30 kHz に保つには ΔL/L ≤ 0.56 % が必要で、振動で簡単にずれます。

### 4.2 RFC（高周波チョーク）に使う場合

| 用途 | 目安 | 注意 |
|---|---|---|
| 10.7 MHz の RFC（インピーダンス ≥ 1 kΩ が欲しい → L ≥ 15 µH） | **このボビンの単層巻きでは届かない**（最大 9〜12 µH 程度） | 線を細くして多層巻き、または市販の 1608 チップインダクタを使う |
| 10.7 MHz の RFC（インピーダンス 300〜600 Ω で足りる場合） | 4.7〜10 µH → 27〜35 T、コア全挿入 | コアを固定。SRF（50〜65 MHz 程度）より十分低い周波数で使う |
| 80〜108 MHz の RFC | **非推奨** | フェライトの損失は大きいが、SRF が使用帯域付近になる。チョークとして使うなら 1608 チップインダクタやフェライトビーズのほうが確実 |

**RFC は同調コイルと違い、L より「使用周波数でインピーダンスが十分高いか」と「SRF が使用周波数より十分高いか」が重要です。** 必ず AWG とオシロで インピーダンスの周波数特性を確認してください。

## 5. 誤差要因のまとめ

| 要因 | 影響の大きさ | 対策 |
|---|---|---|
| LC メータの低 L 誤差 | 100 nH 以下で −60〜−75 % | 100 nH 以下は寸法で作る／共振法で測る |
| 測定周波数 ≠ 使用周波数 | 数 %（フェライトの µ の周波数特性） | 7.2 の共振法で 10.7 MHz 付近で測る |
| シールドケースの有無 | 数 %（ケースで L 減少） | 測定時のケース条件を記録する |
| 巻きピッチ・張力 | 空芯で数 %、コア有りでは小さい | 密巻きをそろえる |
| コアのねじ位置の再現性 | 調整点付近で L ±1 % 程度（推定） | 調整後に固定 |
| ピン・基板の浮遊容量 | 1〜2 pF（仮定） | 同調容量に含めて扱う。今回の実測では影響小 |
| 個体差（コア・ボビン） | 未評価 | 2 個目を作ったら全抜き・全挿入を記録して比較 |

## 7. 追加測定のおすすめ手順（Analog Discovery 3）

### 7.1 L とコア位置のカーブ（最優先）

1. 20 T（または今後よく使う巻数）を巻いたボビンを用意し、**ケースの有無を決めて**記録する
2. コアを全抜きから入れていき、**1/2 回転ごと**に LC メータで L を読む
3. 下の表を埋める（全挿入を越えて L が下がり始めるところまで）

| 回転数（全抜き＝0） | 0 | 0.5 | 1.0 | 1.5 | 2.0 | … | 全挿入 |
|---|---|---|---|---|---|---|---|
| L（µH） | | | | | | | |
| コア上端の突出（mm） | | | | | | | |

### 7.2 10.7 MHz での L と Q（共振法）

1. コイルに**容量が分かっている C0G コンデンサ**（100 p・1 %）を並列につなぐ
2. AWG から **10 kΩ 程度の抵抗**で弱く結合し、オシロで並列タンクの電圧を見る（×10 プローブの 15 pF を C に足す）
3. 周波数を振ってピーク f0 を求める → L = 1 / ((2πf0)² × (C + C_probe))
4. −3 dB 帯域幅 BW から Q = f0 / BW。結合抵抗とプローブの負荷の影響を差し引く
5. 同じコイルを LC メータでも測り、**メータ値と 10.7 MHz での値の比**を記録する（2 章の校正係数になる）

### 7.3 結合係数 k（直列法・LC メータ）

3.4 節と同じ。**コアを実際の調整点に置いたまま**測ること（コア位置で L4 が大きく変わるため、k も位置で変わる可能性がある）。
可能なら L3・L4 も同じコア位置で個別に測っておくと、補間に頼らず k を出せる（3.4 の幅 0.68〜0.72 がなくなる）。

### 7.4 SRF（RFC 用途を考える場合）

コンデンサを外し、コイル単体を 7.2 と同じ方法で振る。ピーク周波数が SRF で、そのときの容量が浮遊容量（プローブ分を差し引く）。
