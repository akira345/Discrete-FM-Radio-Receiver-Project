これは何？
===

生成AIを用いて、専用ICを使用せず日本のワイドFM受信機を設計、自作するプロジェクトです。
可能な限り汎用品を用いて自作し、専用ICの内部構造や動作原理を学習することを目的に作成されました。

また、各種生成AIを使用し、現時点でどこまでアナログ回路の設計、および評価が可能か？を研究する目的でもあります。


## 成果

現時点で以下のものが試作、動作しています。

* FM フロントエンド
  * RF増幅段
  * 局部発振
  * ミキサー
* IF リミッターアンプ + クワドラチャ検波
  * 差動対４段
  * 汎用トランジスタと手巻きコイルによるクワドラチャ検波
* FM MPX 復調
  * 汎用PLL IC + OpAMP + アナログスイッチによるFMステレオの復調
